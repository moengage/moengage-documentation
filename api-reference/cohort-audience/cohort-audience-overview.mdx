## Overview
The MoEngage Cohort Sync API allows you to synchronize cohorts or audiences created in your own ecosystem directly with MoEngage. This server-to-server integration enables you to add or remove users from custom segments dynamically, ensuring your marketing campaigns always target the most relevant audience.



<Info>
The Cohort Sync API **only matches users already present in MoEngage** based on the User ID (`uid`) provided. This API does not create new user profiles.
</Info>

## Cohort Sync Endpoints
The Cohort Sync suite provides a single, high-performance endpoint for membership management:
- [Sync Cohort Members](/api-reference/cohorts/sync-members) - Add or remove users from a custom segment.

## Key Capabilities
* **Automated Segment Creation:** Automatically creates a custom segment in MoEngage if it doesn't already exist.
* **Dynamic Membership:** Real-time updates to segments so that scheduled campaigns engage the latest set of users.
* **No Middleware Needed:** Direct server-to-server calls remove the need for manual CSV uploads or hosting external URLs.

## User Resolution
The API identifies existing user profiles in MoEngage using the following logic:
* **Primary Identifier:** The API relies on the User ID (`uid`).
* **Profile Matching:** The `uid` in your request must match the **Unique User ID** set in MoEngage (typically the ID used for logged-in users).
* **Cross-Device Consistency:** Since devices are associated with a single User ID, updates apply to the user profile regardless of the device they are using.

## Constraints & Limits
To ensure optimal performance, please adhere to the following technical constraints:

| Constraint | Limit |
| :--- | :--- |
| **Request Frequency** | 300 requests per minute (RPM) |
| **Max Payload Size** | 128 KB |
| **Batching** | One cohort action per request (multiple UIDs supported) |

## Implementation Notes
<Note>
**Cohort Naming Convention:**
Ensure your `cohort_name` starts with a **period (.)** and does not contain restricted characters such as `|`, `*`, `?`, `\`, `:`, `<`, `>`, `=`, `$`, or `"`.
</Note>

<Note>
**Payload Efficiency:**
This API is designed for high-frequency, smaller batches. If you need to sync millions of users at once, consider using the MoEngage Bulk Upload features.
</Note>

## FAQs
<AccordionGroup>
  <Accordion title="Does this API create new users if the UID is not found?">
    No. The Cohort Sync API only manages membership for existing MoEngage users. If a provided `uid` does not match an existing profile, that specific entry will be ignored during the sync process.
  </Accordion>
  <Accordion title="Can I add and remove members in a single API call?">
    No. The `action` field in the request body is an enum that accepts either `add_members` or `remove_members`. To perform both actions, you must send two separate requests.
  </Accordion>
  <Accordion title="How soon do changes reflect in my campaigns?">
    Updates are processed dynamically. Campaigns will utilize the updated segment membership during their next scheduled run or trigger event.
  </Accordion>
  <Accordion title="Is there a limit to how many UIDs I can send in one request?">
    There is no hard count on UIDs, but the total request body must stay within the **128 KB** size limit.
  </Accordion>
</AccordionGroup>
