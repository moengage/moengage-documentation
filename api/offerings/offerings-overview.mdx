The MoEngage Offerings API lets you manage offerings programmatically. Use it to create time-bounded promotions and personalized content, update scheduling or targeting on existing offerings, and retrieve paginated lists of offerings for reporting or orchestration workflows.

<Info>
  If this API is not enabled for your account, contact your MoEngage Customer Success Manager (CSM) or the Support team to request enablement.
</Info>

## Endpoints

The Offerings API includes the following endpoints:

- [List Offerings](/api/public-offerings/list-offerings): Returns a paginated list of offerings with filtering by ID, name, status, tags, date range, and creator.
- [Create Offering](/api/public-offerings/create-offering): Creates a new offering in your workspace, including content, scheduling, segmentation, and A/B test configuration.
- [Update Offering](/api/public-offerings/update-offering): Partially updates an existing offering. Only fields present in the request body are changed.

## Authentication

All endpoints use Basic Auth. Pass your MoEngage App ID as the username and your API key as the password.

## Idempotency

The Create and Update endpoints require an `Idempotency-Key` header (UUID v4). Submitting the same key within 24 hours returns the original response without re-executing the operation, making it safe to retry on network failures.

## Rate Limits

Response headers include `X-RateLimit-Limit` (maximum requests per minute) and `X-RateLimit-Reset` (UTC epoch second when the current window resets). If the limit is exceeded, the API returns `429` with a `Retry-After` header.
