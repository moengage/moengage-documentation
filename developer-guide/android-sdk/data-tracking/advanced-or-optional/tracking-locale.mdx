---
title: "Tracking Locale"
description: "Optionally track the device locale in your Android app using the MoEngage SDK."
---

<Warning>
  **Breaking Change (SDK version X.XX.XX)** Public APIs in the Core module now return a `MoETask` object instead of `void`. Update any code that calls these methods if you want to handle success or failure states. For details, see the [release notes](/release-notes/sdks/android#7th-july-2026).
</Warning>

<Info>
  **Optional**

  This is optional and only required if you wish to track the locale.
</Info>

SDK by default does not track locales. To track the Locale set for the given JVM instance call [MoEAnalyticsHelper.trackDeviceLocale()](https://moengage.github.io/android-api-reference/core/com.moengage.core.analytics/-mo-e-analytics-helper/track-device-locale.html).

<CodeGroup>

```Kotlin Kotlin wrap
MoEAnalyticsHelper.trackDeviceLocale(context)
```


```Java Java wrap
MoEAnalyticsHelper.INSTANCE.trackDeviceLocale(context);
```

</CodeGroup>
