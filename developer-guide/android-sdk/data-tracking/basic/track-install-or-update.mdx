---
title: "Track Install or Update"
description: "Differentiate between app installs and updates in the MoEngage Android SDK using the setAppStatus API."
---

<Warning>
  **`setAppStatus()` is not auto-tracked.** You must call this API after `MoEngage.initialiseDefaultInstance()` completes. SDK initialization must finish first — until the SDK is initialized, no events (including install/update) are tracked.
</Warning>

The SDK needs your app to distinguish between a fresh install and an app update. Call `setAppStatus()` after the SDK is initialized:

<CodeGroup>

```kotlin Kotlin wrap
import com.moengage.core.analytics.MoEAnalyticsHelper
import com.moengage.core.model.AppStatus

// Call after MoEngage.initialiseDefaultInstance()
// Use your own logic to detect install vs update
if (isFreshInstall) {
    MoEAnalyticsHelper.setAppStatus(this, AppStatus.INSTALL)
} else {
    MoEAnalyticsHelper.setAppStatus(this, AppStatus.UPDATE)
}
```

```java Java
import com.moengage.core.analytics.MoEAnalyticsHelper;
import com.moengage.core.model.AppStatus;

// Call after MoEngage.initialiseDefaultInstance()
// Use your own logic to detect install vs update
if (isFreshInstall) {
    MoEAnalyticsHelper.INSTANCE.setAppStatus(this, AppStatus.INSTALL);
} else {
    MoEAnalyticsHelper.INSTANCE.setAppStatus(this, AppStatus.UPDATE);
}
```

</CodeGroup>

<Info>
  If you uninstall and reinstall your app again, the SDK considers it as a fresh install.
</Info>
