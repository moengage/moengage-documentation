Use this page to check the support status of MoEngage Android SDK major versions. It lists which versions are current, which are still supported, and which are deprecated, along with deprecation dates. This is the source of truth for Android SDK version status. For how the lifecycle works and what deprecation means for your app, see the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy). To set up the Android SDK, see the [integration guide](/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM).

## Version Support Status

<Card title="Status Definitions">
  | Status | Definition |
  | --- | --- |
  | **Current** | The latest major version. Receives new features, all fixes, and full engineering support. |
  | **Supported** | Older major versions within their 3-year support window. Receive critical fixes and support. |
  | **Deprecated** | Versions outside their support window. No longer receive fixes or support. |
</Card>

| Major Version | Status | Deprecation Date | Notes |
| --- | --- | --- | --- |
| 15.x | Current | April 2029 | Latest major version. Receives new features, fixes, and full support. |
| 14.x | Supported | April 2028 | Receives support. |
| 13.x | Supported | April 2028 | Receives support. |
| 12.x and below | Deprecated | April 2027 | Support, debugging, and fixes are no longer available. Data continues to flow. Upgrade to the current or a supported version. |

<Note>
  MoEngage supports each major version for a minimum of 3 years from its release; deprecation then takes effect the following April. See the [SDK Deprecation Policy — Support Window](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy#support-window) for details. This table is updated when MoEngage announces further deprecations. To receive advance notice, subscribe to the SDK newsletter and ensure your workspace administrator email is current.
</Note>

## Understanding Deprecated Status

A deprecated version continues to send and receive data. MoEngage does not block traffic. After the deprecation date, MoEngage no longer debugs, fixes, or supports issues specific to that version, and the resolution for any issue is to upgrade to the current or a supported version. Fixes ship forward in supported versions and are not back-ported. For the complete policy, see the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy).

## Upgrading to a Supported Version

- Refer to the [Android SDK release notes](/release-notes/sdks/android) to review changes across versions.
- Follow the [Android SDK release checklist](/developer-guide/android-sdk/checklist/release-checklist) to plan and validate your upgrade.
- Contact your MoEngage Customer Success Manager (CSM) or the Support team for help planning an upgrade.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Does deprecation stop my app from sending data?">
    Deprecated versions continue to send and receive data normally. MoEngage does not block traffic on deprecated versions.
  </Accordion>
  <Accordion title="Will I still receive fixes, security patches, and dependency updates on a deprecated version?">
    Fixes — including critical bug fixes, security patches, and dependency updates — are not available on deprecated versions. To receive a fix, upgrade to the current or a supported version.
  </Accordion>
  <Accordion title="Can I stay on a deprecated version after it is deprecated?">
    Apps on deprecated versions continue to run and data continues to flow. However, MoEngage no longer provides support, debugging, or fixes for deprecated versions. Upgrading to the current or a supported version using the [Android SDK release notes](/release-notes/sdks/android) and the [Android SDK release checklist](/developer-guide/android-sdk/checklist/release-checklist) ensures you receive continued support and fixes.
  </Accordion>
  <Accordion title="How do I receive advance notice of deprecations?">
    MoEngage sends advance notice 6 to 12 months before the deprecation date through email to workspace administrators, the quarterly SDK newsletter, in-dashboard notices, and SDK release notes. See the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy) for the full notification schedule.
  </Accordion>
</AccordionGroup>
