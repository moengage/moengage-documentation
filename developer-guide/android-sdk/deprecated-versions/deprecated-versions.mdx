This page is the source of truth for MoEngage Android SDK version support status. For how the deprecation process works, see the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy).

## Version Support Status

| Status | What it means |
| --- | --- |
| **Current** | The latest major version. Receives new features, all bug fixes, security patches, and full engineering support. |
| **Supported** | An older major version that still receives critical fixes (crash-level bugs, security vulnerabilities, broken dependencies). No new features. |
| **Deprecated** | Support has ended. No fixes, debugging, or support tickets accepted. Data continues to flow until the end-of-support date, after which MoEngage servers stop accepting data from this version. |

| Major version | Status | End-of-support date | Notes |
| --- | --- | --- | --- |
| 15.x | Current | — | Latest major version. Receives new features, fixes, and full support. |
| 14.x | Supported | — | Receives critical fixes. No new features. |
| 13.x | Supported | — | Receives critical fixes. No new features. |
| 12.x and below | Deprecated | April 30, 2027 | No support, debugging, or fixes. Data continues to flow until April 30, 2027. Upgrade to 13.x or later. |

<Note>
  Version numbers and end-of-support dates reflect the first deprecation under this policy. This table is updated when MoEngage announces further deprecations. To receive advance notice, subscribe to the SDK newsletter and ensure your workspace administrator email is current — see [Deprecation Notifications](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy#deprecation-notifications).
</Note>

## Deprecated Version Behavior

A deprecated version continues to send and receive data. MoEngage does not block traffic. After the end-of-support date, MoEngage no longer debugs, fixes, or supports issues specific to that version. To resolve any issue on a deprecated version, upgrade to a supported version. Fixes ship forward in supported versions and are not back-ported.

For the complete policy, see the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy).

## Upgrading to a Supported Version

To move to a supported version, refer to the [Android SDK release checklist](/developer-guide/android-sdk/checklist/release-checklist). The latest released versions are listed in the [Android SDK release notes](/release-notes/sdks/android).

For help planning an upgrade, contact your MoEngage Customer Success Manager (CSM) or the Support team.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Does deprecation stop my app from sending data?">
    No. Deprecated versions continue to send and receive data normally. MoEngage does not block traffic on deprecated versions. Data flow stops only when the end-of-support date passes and enforcement becomes active.
  </Accordion>
  <Accordion title="Will I still receive bug fixes on a deprecated version?">
    No. Fixes ship in current, supported versions only and are not back-ported. To receive a fix, upgrade to a supported version.
  </Accordion>
  <Accordion title="Can I stay on a deprecated version past the end-of-support date?">
    Your app continues to run, but MoEngage servers stop accepting data from deprecated versions after the enforcement date (April 30, 2027). Push, in-app, and analytics stop delivering for users on those versions. Upgrading to a supported version using the [Android SDK release checklist](/developer-guide/android-sdk/checklist/release-checklist) restores full functionality.
  </Accordion>
  <Accordion title="How do I receive advance notice of deprecations?">
    MoEngage sends advance notice 6 to 12 months before the end-of-support date through email to workspace administrators, the quarterly SDK newsletter, in-dashboard notices, and SDK release notes. See the [SDK Deprecation Policy](/developer-guide/components-for-sdk/platform-updates/sdk-deprecation-policy) for the full notification schedule.
  </Accordion>
</AccordionGroup>
