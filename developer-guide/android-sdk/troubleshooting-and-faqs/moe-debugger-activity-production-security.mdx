## Why is MoEDebuggerActivity exported?

The `MoEDebuggerActivity` is part of the `sdk-debugger` module and is exported by design to enable the **SDK Logger** — a QR-based debugging tool for post-release campaign debugging. This activity cannot be disabled remotely once compiled into your app.

## Remove the debugger from production

If your security or compliance policy requires the debugger to be removed from production builds, exclude the `sdk-debugger` module in your `build.gradle.kts`:

```kotlin build.gradle.kts wrap
dependencies {
    implementation(platform("com.moengage:android-bom:<bomVersion>")) {
        exclude(group = "com.moengage", module = "sdk-debugger")
    }
}
```

Once excluded, the `MoEDebuggerActivity` will not be present in your compiled application, and the SDK Logger feature will be unavailable.
