## What is MoEDebuggerActivity?

The MoEngage Cordova SDK bundles the native MoEngage Android SDK, so your Android build includes `MoEDebuggerActivity` — a component that supports on-device SDK debugging. To learn what it does and how to remove it if needed, refer to [this FAQ](/developer-guide/android-sdk/troubleshooting-and-faqs/troubleshooting-and-faqs).
