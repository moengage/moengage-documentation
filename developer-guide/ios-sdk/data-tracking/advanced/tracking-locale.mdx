---
title: "Tracking Locale"
description: "Track the locale settings of your user's device in your iOS app using the MoEngage SDK."
---

For tracking the locale settings of the user device use [_trackLocale()_](https://moengage.github.io/ios-api-reference/Classes/MoEngageSDKAnalytics.html#/c:@M@MoEngageAnalytics@objc\(cs\)MoEngageSDKAnalytics\(im\)trackLocale) method as shown below:

<CodeGroup>

```swift Swift wrap
MoEngageSDKAnalytics.sharedInstance.trackLocale()
```


```objective-c Objective C wrap
[[MoEngageSDKAnalytics sharedInstance] trackLocale];
```

</CodeGroup>

<Note>
  Starting with iOS SDK [11.0.0](/release-notes/sdks/ios#22nd-july-2026), `trackLocale()` returns a typed task object (`MoEngageTrackDeviceLocaleTask`) instead of `Void`. Direct calls like the ones above compile unchanged. Attach `.onSuccess` / `.onFailure` to the returned task to observe the outcome. If some locale sub-attributes are skipped but at least one is accepted, the task succeeds and the result carries both the accepted and skipped attributes; the task fails with the `trackLocaleSubAttributeFailed` module code only when every sub-attribute is skipped. Refer to [Failure Reason Codes](/developer-guide/ios-sdk/migration/migration-to-sdk-version-11-0-0#failure-reason-codes).
</Note>
