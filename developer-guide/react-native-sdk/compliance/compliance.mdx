Use the APIs below to control what the MoEngage SDK tracks, based on the consent a user has given.

## Enable or Disable Data Tracking

To stop the SDK from tracking custom events and user attributes, call `disableDataTracking()`.

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.disableDataTracking();
```

</CodeGroup>

The SDK rejects all events and user attributes until you call `enableDataTracking()`. Data tracking is enabled by default.

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.enableDataTracking();
```

</CodeGroup>

<Note>
  `enableDataTracking()` and `disableDataTracking()` are available from **react-native-moengage** version **10.0.0**. They replace `optOutDataTracking(false)` and `optOutDataTracking(true)`.
</Note>

## Enable or Disable the SDK

To stop the SDK from tracking any user information or sending any data to MoEngage, call `disableSdk()`.

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.disableSdk();
```

</CodeGroup>

All SDK APIs are non-operational until you call `enableSdk()`. The SDK is enabled by default, so call `enableSdk()` only if you disabled it earlier.

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.enableSdk();
```

</CodeGroup>

<Note>
  While the SDK or data tracking is disabled, the SDK drops `identifyUser()` calls instead of caching them. Call `identifyUser()` again after you re-enable the SDK or data tracking. For more information, refer to [Tracking User Attributes and User Identity](/developer-guide/react-native-sdk/data-tracking/tracking-user-attributes-and-user-identity).
</Note>

## Delete User Data

To delete the current user's profile from the MoEngage server, refer to [Delete User From MoEngage Server](/developer-guide/react-native-sdk/data-tracking/delete-user-from-moengage-server).
