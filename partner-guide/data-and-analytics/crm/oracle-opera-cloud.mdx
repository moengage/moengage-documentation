[Oracle OPERA Cloud](https://www.oracle.com/hospitality/) is a property management system (PMS) used by hotels to manage reservations, guest profiles, and stays. The MoEngage and OPERA Cloud integration streams hotel business events, such as reservations, check-ins, check-outs, and guest profile changes, from OPERA Cloud into MoEngage through the Oracle Hospitality Integration Platform (OHIP).

Each event arrives in MoEngage as a user event, so you can build pre-arrival, in-stay, and post-stay guest journeys on data that reflects the current state of the property.

## Supported Events

The following table describes the events that OPERA Cloud sends to MoEngage:

| Event | Description | Use case |
| --- | --- | --- |
| Reservation Created | A new booking is confirmed. | Trigger a pre-arrival campaign. |
| Reservation Updated | Booking details are modified. | Re-trigger or suppress a journey. |
| Reservation Cancelled | A booking is cancelled. | Trigger a win-back or feedback campaign. |
| Reservation Checked-In | The guest arrives at the property. | Send an in-stay upsell or welcome message. |
| Reservation Checked-Out | The guest completes the stay. | Send a post-stay NPS survey or review request. |
| Guest Profile Updated | Contact or preference information changes. | Enrich the guest profile in MoEngage. |

## How the Integration Works

The integration uses the OHIP Streaming API, which maintains a persistent WebSocket subscription rather than polling OPERA Cloud on a schedule. Once the subscription is established, OPERA Cloud pushes each business event as it occurs.

MoEngage hosts and operates a listener that does the following:

- Maintains a continuous WebSocket connection to OHIP.
- Authenticates through OAuth 2.0 client credentials against OPERA Cloud Identity Management (OCIM), using the MoEngage partner application key.
- Transforms each OPERA Cloud event payload into the MoEngage user and event schema.
- Sends the transformed data to MoEngage through the Data API.

Because MoEngage hosts the listener, you do not need to set up Oracle Integration Cloud (OIC) or run a connectivity agent in your own environment.

## Set Up the Integration

MoEngage configures this integration for you. To request it, perform the following steps:

1. Contact your MoEngage Customer Success Manager (CSM) or [MoEngage Support](https://help.moengage.com/hc/en-us/requests/new) and request the Oracle OPERA Cloud integration.
2. In the request, provide the following details:

   | Detail | Description |
   | --- | --- |
   | Enterprise ID | The unique identifier of the enterprise for which the OHIP client was created. |
   | Chain Code | The code that identifies your hotel chain in OPERA Cloud. |
   | Property Code | The code that identifies the property to stream events from. |

3. Approve the access request that MoEngage raises through the OHIP Developer Portal. Sign in to your own OHIP portal instance to grant approval.

OHIP uses the Enterprise ID, Chain Code, and Property Code to authenticate the connection, so the request cannot proceed without all three. After you approve the access request, MoEngage completes the technical configuration and begins streaming events into your workspace.
