Create and manage WhatsApp templates directly from MoEngage without switching to your Meta partner's portal. Once your Meta account is configured, you can create templates, submit them to Meta for approval, and track their approval status all from a single interface. This streamlined workflow eliminates the need to create templates externally and sync them back to MoEngage.

<Info>
  You can create, configure, and submit templates to Meta for approval directly from MoEngage. Before you begin, ensure that you have access to all the approved WhatsApp templates before adding templates to MoEngage. You can access the templates from the BSP Dashboards.
</Info>

For information about adding your already approved/whitelisted WhatsApp templates in MoEngage, refer to [Configure Meta](https://www.moengage.com/docs/partner-guide/messaging-channels/whatsapp-providers/meta/configure-meta).

## Create a Meta Template

1. Navigate to **Settings** **\> Channels \>** **WhatsApp**.
2. Select the **Approved templates** tab and click on the **\+ Template** button.

<Frame>
  ![Screenshot 2026 07 30 At 3 54 52 PM](/images/Screenshot-2026-07-30-at-3.54.52-PM.png "Screenshot 2026 07 30 At 3 54 52 PM")
</Frame>

4. Configure the template by adding the required components.
5. Click the **Save** or **Submit for approval** button.

  ![Screenshot 2026 07 30 At 3 59 12 PM](/images/Screenshot-2026-07-30-at-3.59.12-PM.png "Screenshot 2026 07 30 At 3 59 12 PM")

<Info>
  When you select **Submit for approval**, MoEngage submits the template to Meta for approval. When you select **Save**, MoEngage saves the template only. Templates saved this way must be manually created and submitted to Meta for approval.
</Info>

| Field | Description |
| --- | --- |
| **Name** | Enter the template name exactly as it appears on the BSP side. The name can have up to 100 characters. |
| **Service Provider** | Choose Meta from the dropdown (or your BSP) with which you want to send this templated message. Note that WhatsApp templates are approved at the WhatsApp Business Account (WABA) level, which can belong to only one BSP. Select the BSP that is compatible with your template. |
| **Sender Profile** | Choose the Meta profile with which this template is approved. You can select multiple Meta profiles if they are from the same BSP and are under the same WABA. |
| **Language** | Select the language for the template content. This value determines the language of your template and should match the language specified on the BSP/WSP side. |
| **Category** | Select the category type from the dropdown. WhatsApp allows sending messages that belong to one of the following categories:<br />• Marketing<br />• Utility |
| **Template Type** | This field is visible only if you have selected the Category field as Marketing. Select the template type from the dropdown menu. |

<Info>
  The Carousel, Limited Time Offer, Coupon Code, and WhatsApp templates, and up to 10 buttons are supported only for GupShup, Karix & Infobip.
</Info>

As supported by WhatsApp, you can configure selective fields as:

- **Static**: Static fields are fixed on the Template level. For example, static images can be used to send the same image in all messages to target users across all campaigns where this template is used.
- **Dynamic**: Dynamic fields are flexible and can be configured during campaign creation. A dynamic image can be used to personalize for each campaign or each user in that campaign.
- **Dynamic Link Tracking**: Dynamic link tracking allows you to track clicks on buttons with Navigation as an action. This is available only for Navigation buttons and for Gupshup as a provider.

## Headers

Headers are optional and can be of the following types:

- Text (up to 60 characters, can include 1 placeholder)
- Image
- Video
- Document
- Location

The non-text header can be static or dynamic. They can use a fixed image or document link or a personalized image/document for every user. Dynamic fields will be available for configuration at the time of campaign creation. For more information, refer to [Image Personalization](https://help.moengage.com/hc/en-us/articles/30926654573972-Overview#h_01JJKNJN9PNQV0NSPSNZCPCFN1).

Here are the supported media types, media formats, and file sizes that MoEngage supports:

| Content-Type | Supported Format and file size |
| --- | --- |
| **Image** | The supported image types are JPG, JPEG, and PNG. The maximum file size is 5MB. |
| **Document** | The supported document type is PDF. The maximum document size is 5MB. |
| **Video** | The supported file types are MP4 and 3GPP. The maximum file size is 15MB. |

## Template Status

Once you submit a template for approval, it progresses through the following statuses:

| Status | Description |
| --- | --- |
| **Under Review** | The template has been submitted and is currently being reviewed by Meta. |
| **Approved** | The template has been approved by Meta and is ready to use in your WhatsApp campaigns. |
| **Rejected** | Meta rejected the template. Review the rejection reason, update the template if required, and submit it again. |
