# Introduction

[Spoonacular](https://spoonacular.com/food-api) is a food knowledge platform covering recipe discovery, ingredient parsing, meal planning, and detailed nutritional analysis, well suited for health and wellness campaign personalization.

# MoEngage × Spoonacular

The MoEngage × Spoonacular integration allows you to personalize food, health, and grocery campaigns with live recipe and nutrition data at send time. Common use cases include recommending recipes based on a user's dietary preferences, surfacing healthy meal ideas in a wellness app, or promoting grocery products with recipe inspiration.

# Integration

<Info>
**Prerequisites**

Ensure you have a Spoonacular account with an active API key. Free keys are available at [spoonacular.com/food-api](https://spoonacular.com/food-api/console#Dashboard). The free tier allows 150 points per day.
</Info>

## Step 1: Get Your Spoonacular API Key

1. Navigate to [spoonacular.com/food-api](https://spoonacular.com/food-api/console#Dashboard) and create a free account.
2. Your API key is displayed on your console dashboard. Copy it.

## Step 2: Set Up the Content API on MoEngage

1. Navigate to **Dashboard > Settings > APIs** and open the **Content API** tab.
2. Click **Add Content API**.
3. Fill in the details using the table below as a reference.

| Key | Value |
|---|---|
| **Name** | Choose a descriptive name, for example `Spoonacular Recipe Search`. |
| **Method** | GET |
| **API URL** | `https://api.spoonacular.com/recipes/complexSearch`. Refer to the [Spoonacular documentation](https://spoonacular.com/food-api/docs) for all endpoints. |

For **Key Value Parameters**, add the following:

| Parameter | Example value | Notes |
|---|---|---|
| `apiKey` | *Your API key* | Required for every request. |
| `diet` | `@user.diet_preference` | Filter by diet: `vegetarian`, `vegan`, `gluten free`, `ketogenic`, and others. |
| `cuisine` | `@user.cuisine_preference` | Filter by cuisine type. |
| `number` | `3` | Number of results to return. |
| `addRecipeInformation` | `true` | Set to `true` to include image, title, and summary in the response. |

4. Click **Validate** to confirm the platform returns a response, then click **Save**.

Once saved, refer to [Content APIs](/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) to learn how to reference response fields inside your campaign templates. For setup details, see [Add a Content API](/user-guide/settings/advanced-settings/add-a-content-api).

## Understanding the API Response

The response contains a `results` array. Each object represents one recipe.

![Spoonacular API response shown in the MoEngage Content API test view](/images/spoonacular-content-api-response.png)

| Response field | Template variable example | Description |
|---|---|---|
| `results[0].title` | `{{ContentApi.results[0].title}}` | Recipe name. |
| `results[0].image` | `{{ContentApi.results[0].image}}` | Recipe photo URL. |
| `results[0].readyInMinutes` | `{{ContentApi.results[0].readyInMinutes}}` | Preparation time in minutes. |
| `results[0].servings` | `{{ContentApi.results[0].servings}}` | Number of servings. |
| `results[0].sourceUrl` | `{{ContentApi.results[0].sourceUrl}}` | Full recipe URL — use as a CTA. |
