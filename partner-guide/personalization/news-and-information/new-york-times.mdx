# Introduction

[The New York Times](https://developer.nytimes.com) provides official developer access to its editorial content, covering top stories, article search, most popular articles, books bestseller lists, and movie reviews.

# MoEngage × New York Times

The MoEngage × New York Times integration allows you to pull authoritative editorial content into your campaigns at send time via Content APIs. Common use cases include surfacing top stories in a content-led email newsletter, enriching B2B campaigns with relevant news, or personalizing in-app messages with articles matching a user's interests.

# Integration

<Info>
**Prerequisites**

Ensure you have a New York Times developer account with an active API key. Keys are free and available at [developer.nytimes.com/get-started](https://developer.nytimes.com/get-started).
</Info>

## Step 1: Get Your New York Times API Key

1. Navigate to [developer.nytimes.com/get-started](https://developer.nytimes.com/get-started) and sign in or create an account.
2. Go to **My Apps** and create a new app. Enable the APIs you need for campaign personalization, for example **Top Stories** and **Article Search**.
3. Copy the API key from your app dashboard.

<Note>
**Rate limit**

The free tier allows 500 requests per day and 5 requests per minute. Keep this in mind when planning campaign send volumes.
</Note>

## Step 2: Set Up the Content API on MoEngage

1. Navigate to **Dashboard > Settings > APIs** and open the **Content API** tab.
2. Click **Add Content API**.
3. Fill in the details using the table below as a reference.

| Key | Value |
|---|---|
| **Name** | Choose a descriptive name, for example `NYT Top Stories`. |
| **Method** | GET |
| **API URL** | `https://api.nytimes.com/svc/topstories/v2/home.json`. Replace `home` with a section name such as `technology`, `sports`, `business`, or `arts` to filter by topic. Refer to the [Top Stories API documentation](https://developer.nytimes.com/docs/top-stories-product/1/overview) for the full list of sections. |

For **Key Value Parameters**, add the following:

| Parameter | Example value | Notes |
|---|---|---|
| `api-key` | *Your API key* | Required for every request. |

4. Click **Validate** to confirm the platform returns a response, then click **Save**.

Once saved, refer to [Content APIs](/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) to learn how to reference response fields inside your campaign templates. For setup details, see [Add a Content API](/user-guide/settings/advanced-settings/add-a-content-api).

## Understanding the API Response

The response contains a `results` array. Each object represents one article.

| Response field | Template variable example | Description |
|---|---|---|
| `results[0].title` | `{{ContentApi.results[0].title}}` | The article headline. |
| `results[0].abstract` | `{{ContentApi.results[0].abstract}}` | A short summary of the article. |
| `results[0].url` | `{{ContentApi.results[0].url}}` | The full NYT article URL. |
| `results[0].multimedia[0].url` | `{{ContentApi.results[0].multimedia[0].url}}` | Thumbnail image URL for the article. |
| `results[0].section` | `{{ContentApi.results[0].section}}` | The editorial section, for example "Technology". |
| `results[0].published_date` | `{{ContentApi.results[0].published_date}}` | Publication date in ISO 8601 format. |
