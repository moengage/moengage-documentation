## MoEngage Go: The MoEngage Mobile App

The MoEngage mobile app (MoEngage Go) is a companion to the MoEngage web dashboard, focused on the tasks you need to complete when you are away from your desk. You can monitor campaign performance, manage running campaigns, approve campaigns pending review, and respond to critical alerts from your phone. With the app, you can:

- View active and scheduled campaigns.
- Approve or reject items pending review.
- Pause or stop live sends.

Sign-in supports SSO, Google, and email, with the same roles and permissions as the web app. Campaign creation and editing remain on desktop because those workflows require the full interface.

MoEngage Go is now available on the [iOS App Store](https://apps.apple.com/us/app/moengage-go/id6755712030?utm_source=help_docs&utm_medium=referral&utm_campaign=app_download) and [Android Play Store](https://play.google.com/store/apps/details?id=com.moengage.go&utm_source=help_docs&utm_medium=referral&utm_campaign=app_download).

For more information, refer to [MoEngage Go: Overview](/user-guide/moengage-go/moengage-go-overview).

## Simulate a Decision Policy for Offer Decisioning

MoEngage has added a simulator to Offer Decisioning, which lets you test a Decision Policy before and after it goes live. Select a specific known user, a random user, or an anonymous visitor, and run the policy against them in real time. The results show which offerings are selected and in what order, which offerings were eligible but not selected, and which offerings failed segment or capping checks. For the Custom Formula ranking strategy, the results include the score calculation for each offering. You can also test in-session attributes such as device type, country or city, and language to see how contextual signals change which offers surface.

For more information, refer to [Simulate a Decision Policy](/user-guide/decisioning/offer-decisioning/simulate-decision-policy).

## Custom Alerts for Funnels, Retention, and Session & Source

MoEngage has extended Custom Alerts, previously available in Behavior analytics, to the Funnels, Retention, and Session & Source analysis types.

- For Funnels, you can alert on the count of users converting between any two steps.
- For Retention, you can watch a specific retention day (such as D7 or D30) and get notified when it increases or decreases by a percentage or value.
- For Session & Source, you can track metrics such as session count, bounce rate, and revenue across sources.

For more information, refer to [Alerts in Analytics](/user-guide/analyze/analytics/alerts-in-analytics).

## Analytics Tables Migrated to AG Grid

MoEngage has migrated analytics tables across Behavior, Funnels, Retention, Session & Source, and User Analysis to AG Grid. The updated tables let you resize columns within minimum and maximum limits, sort any column ascending or descending with a third-click reset, and search across all rows and columns. Column filters support AND/OR conditions, multi-column filtering, and an advanced query builder.

For more information, refer to [Getting Started with Analytics](/user-guide/analyze/analytics/getting-started-with-analytics/overview#tables).

## User Affinity Enhancements

MoEngage has upgraded User Affinity in Segments. User Affinity now works with Teams, which are also now available in Analytics. You can use object data types within event attribute filters when building affinity segments, and upgraded filters give you more ways to define affinity-based audiences.

For more information, refer to [Affinity Segments](/user-guide/segment/segment-operations/affinity-segments).

## Flows Assist: Iterative Editing

Flows Assist now lets you refine a flow across multiple turns within the same session. After Flows Assist builds a flow, you can ask it to change the branching logic, delay structure, or other elements, and it updates the flow. Each regeneration creates a new version (V1, V2, V3, and so on), and you can select an earlier version to continue from or take to the canvas. This editing applies only to flows being built in an active Flows Assist session. Once you select **Edit in Canvas**, the session ends, and Flows Assist cannot edit pre-existing drafts. Target Audience still defaults to All Users, campaign stages remain placeholders, and content is not generated. 

This feature is available for clients who already have the Flows Assist MVP enabled on DC-03.

For more information, refer to [Merlin AI Flows Assist](/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-flows-assist).

## Campaign Insight Agent for Event-Triggered Campaigns

The Merlin AI Campaign Insights Agent now supports Event-Triggered campaigns on Email and Push, in addition to existing support for One-Time and Periodic campaigns.

For Event-Triggered campaigns, the agent offers a dedicated set of prompts focused on the trigger funnel — from the triggering event through to conversion:

- **Summarize performance**: A snapshot of your trigger funnel from event to conversion, highlighting what worked, where drop-offs happened, and next steps
- **Find winning patterns**: Compares past triggered campaigns to surface strategies that drove the best results
- **Analyze performance trends**: Spots week-over-week spikes and dips across key metrics so you can track how the campaign is trending over time
- **Optimize trigger playbook**: Recommends improvements to trigger timing, delay, and re-entry settings to drive better conversions
- **Diagnose delivery failures**: Uncovers root causes of drop-offs across the trigger funnel and suggests corrective actions

**Availability**: This is part of the existing Early Access Campaign Insights Agent feature. If it's already enabled for your account, Event-Triggered support is included. If not yet enabled, contact your MoEngage CSM or Support team.

For more information, refer to [Campaign Insights Agent](/user-guide/ai-and-intelligence/merlin-ai/campaign-insights-agent).

## Feed Upload Revamp

MoEngage has revamped catalog feed uploads into a two-step workflow. In the first step, you upload a CSV, TSV, or XML file and preview the data before processing. In the second step, the system maps your file columns to catalog attributes automatically, and you can adjust the mapping manually. Mandatory fields are enforced before processing, case-sensitivity mismatches are handled, and saved mapping configurations are reused for later uploads.

For more information, refer to [Catalogs](/user-guide/content/recommendations/prerequisites/catalogs#add-feeds-to-a-catalog).

## Workspace Classification

MoEngage now supports Workspace Classification, allowing you to tag workspaces as Production or Non-Production to facilitate a staged, automated feature release cycle.

With this feature, you can:

- Test updates safely by routing new features to Non-Production workspaces before rolling them out to Production environments.
- Stay informed with automated email notifications at each stage of the rollout cycle.
- Manage classifications easily via **Settings** \> **Account** \> **General Settings** for existing workspaces, or directly during onboarding for new ones.
- Protect live campaigns with an automatic Non-Production default for any unclassified workspace.

<Info>
  This feature is enabled for all customers on the Enterprise plan on DC-03.
</Info>

For more information, refer to [Workspace Settings](/user-guide/settings/account/general-settings/workspace-settings).
