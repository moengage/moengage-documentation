## Simulate a Decision Policy for Offer Decisioning

MoEngage has added a simulator to Offer Decisioning that lets you test a Decision Policy before and after it goes live. Select a specific known user, a random user, or an anonymous visitor, and run the policy against them in real time. The results show which offerings are selected and in what order, which offerings were eligible but not selected, and which offerings failed segment or capping checks. For the Custom Formula ranking strategy, the results include the score calculation for each offering. You can also test in-session attributes such as device type, country or city, and language to see how contextual signals change which offers surface.

For more information, refer to [Simulate a Decision Policy](/user-guide/decisioning/offer-decisioning/simulate-decision-policy).

## Custom Alerts for Funnels, Retention, and Session & Source

MoEngage has extended Custom Alerts, previously available in Behavior analytics, to the Funnels, Retention, and Session & Source analysis types.

- For Funnels, you can alert on the count of users converting between any two steps.
- For Retention, you can watch a specific retention day (such as D7 or D30) and get notified when it increases or decreases by a percentage or value. 
- For Session & Source, you can track metrics such as session count, bounce rate, and revenue across sources.

For more information, refer to [Alerts in Analytics](/user-guide/analyze/analytics/alerts-in-analytics).

## Analytics Tables Migrated to AG Grid

MoEngage has migrated analytics tables across Behavior, Funnels, Retention, Session & Source, and User Analysis to AG Grid. The updated tables let you resize columns within minimum and maximum limits, sort any column ascending or descending with a third-click reset, and search across all rows and columns. Column filters support AND/OR conditions, multi-column filtering, and an advanced query builder.

For more information, refer to [Getting Started with Analytics](/user-guide/analyze/analytics/getting-started-with-analytics/overview#tables).

## User Affinity Enhancements

MoEngage has upgraded User Affinity in Segments. User Affinity now works with Teams, which are also now available in Analytics. You can use object data types within event attribute filters when building affinity segments, and upgraded filters give you more ways to define affinity-based audiences.

For more information, refer to [Affinity Segments](/user-guide/segment/segment-operations/affinity-segments).

## Flows Assist: Iterative Editing

Flows Assist now lets you refine a flow across multiple turns within the same session. After Flows Assist builds a flow, you can ask it to change the branching logic, delay structure, or other elements, and it updates the flow. Each regeneration creates a new version (V1, V2, V3, and so on), and you can select an earlier version to continue from or take to the canvas. This editing applies only to flows being built in an active Flows Assist session. Once you select **Edit in Canvas**, the session ends, and Flows Assist cannot edit pre-existing drafts. Target Audience still defaults to All Users, campaign stages remain placeholders, and content is not generated. This is available for clients who already have the Flows Assist MVP enabled on DC3, with rollout to other clusters planned.

For more information, refer to [Merlin AI Flows Assist](/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-flows-assist).

## Campaign Insight Agent for Event Triggered Campaigns

The Merlin AI Campaign Insight Agent now supports Event Triggered campaigns on the Push and Email channels, in addition to One-Time and Periodic campaigns. For Event Triggered campaigns, the agent provides spike and dip analysis of campaign volume, trigger behavior intelligence on which events are firing and from which segments, event-level root cause diagnosis across the trigger condition, audience qualifier, timing window, and creative, and trigger frequency benchmarking against your historical baselines. If the Insight Agent is already enabled for your account, this update is applied automatically. SMS and RCS channel support is planned for a later phase.

For more information, refer to [Campaign Insights Agent](/user-guide/ai-and-intelligence/merlin-ai/campaign-insights-agent).

## Feed Upload Revamp

MoEngage has revamped catalog feed uploads into a two-step workflow. In the first step, you upload a CSV, TSV, or XML file and preview the data before processing. In the second step, the system maps your file columns to catalog attributes automatically, and you can adjust the mapping manually. Mandatory fields are enforced before processing, case-sensitivity mismatches are handled, and saved mapping configurations are reused for later uploads.

For more information, refer to [Catalogs](/user-guide/content/recommendations/prerequisites/catalogs#add-feeds-to-a-catalog).

## Workspace Classification

MoEngage has added Workspace Classification, which lets you tag each workspace as Production or Non-Production from the dashboard. The classification supports a staged, automated release cycle in which new features roll out to Non-Production workspaces first, followed by Production workspaces, with email notifications at each stage. To classify an existing workspace, go to **Settings \> Account \> General Settings**, select **Production** or **Non-Production** under **Workspace Classification**, and select **Save**. For new workspaces, classification is part of the onboarding flow. Any workspace without a classification defaults to Non-Production. This feature is enabled for all customers on the Enterprise plan on DC3.

For more information, refer to [Workspace Settings](/user-guide/settings/account/general-settings/workspace-settings).
