Authentication is done via Basic Auth. This requires a Base64-encoded string of your credentials in the format `username:password`.

- **Username**: Use your MoEngage Workspace ID (also known as the App ID). Find it in the MoEngage dashboard at **Settings** \> **Account** \> **API keys**.
- **Password**: Use an API key that has access to this API. In the MoEngage dashboard, go to **Settings** \> **Account** \> **API keys**, click **\+ Create new key**, enter a **Key name**, select this API under **Select APIs for access**, and click **Save**.

<Note>
  The API key dashboard is an Early Access feature. To enable it for your account, contact your MoEngage Customer Success Manager (CSM) or the Support team.
</Note>

A key works only for the APIs selected on it. Requests sent with a key that does not cover this API fail with `401` or `403`. To change what a key covers, open **View key details** and select **Edit key details**.

Regenerating a key invalidates the old value immediately. To rotate a key without downtime, create a second key with the same access, move your integrations to it, and then archive the old key.

For key details, regeneration, archiving, legacy keys, and the audit log of key actions, refer to [API Key Dashboard](/user-guide/settings/account/api-and-api-keys/api-key-dashboard).
