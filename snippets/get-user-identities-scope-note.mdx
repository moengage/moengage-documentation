Flutter, Unity, Capacitor, and Cordova user attribute pages. */}

<Note>
  This method reads from the SDK's local storage on the device where you call it. It returns only the identifiers that were set on that device, as they exist at the time of the call.

  The returned identifiers do not include:

  - Identifiers set on the user's other devices.
  - Identifiers set through server-to-server APIs or data imports.
  - The outcome of identity resolution merges or any other server-side resolution.

  For more information, see [Unified Identity (Identity Resolution)](/user-guide/data/user-data/unified-identity-identity-resolution).
</Note>
