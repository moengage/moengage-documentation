<Note>
  If a network issue prevents the identifier from reaching the MoEngage server, the SDK caches the `identifyUser()` call and retries automatically once the network is available or the next time the app opens. If the MoEngage SDK or data tracking is disabled, the SDK drops the `identifyUser()` call instead of caching it — call `identifyUser()` again after tracking is re-enabled.
</Note>
