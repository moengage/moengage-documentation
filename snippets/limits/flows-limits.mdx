| Limit | Value | Scope | If exceeded | How to increase |
| --- | --- | --- | --- | --- |
| Wait node (rolling duration) — minimum | 5 minutes | Per node | Shorter delays can't be set | Not configurable |
| Wait node (rolling duration) — maximum | 30 days | Per node | Users who arrive after the window elapses are dropped from the flow | Not configurable |
| Wait till specific date — maximum | 60 days from today | Per node | Users who enter after the target date are dropped silently, with no error | Not configurable |
| Entry delay ("With Delay") — range | 5 minutes to 30 days | Per flow | Values outside the range can't be set | Not configurable |
| Time-based flows — max users per instance | 10,000,000 | Per flow instance | Additional users can't enter the run | Not configurable |
| A/B Split / IPO nodes — maximum per flow | 10 | Per flow | You can't add more A/B Split or IPO nodes | Not configurable |
| Conditional Split — maximum paths | 25 | Per node | You can't add more branches | Not configurable |
| Conversion goals per flow — maximum | 5 | Per flow | You can't add more conversion goals | Not configurable |
| Conversion goal tracking window — maximum | 10 days | Per flow | Conversions after the window aren't credited | Not configurable |
| Condition stage lookback — maximum | 30 days | Per stage | Longer evaluation windows can't be set | Not configurable |
| Condition stage evaluation window — minimum | 5 minutes | Per stage | Shorter evaluation windows can't be set | Not configurable |
| Linked Conditions — max in-flight evaluations per user | 10 | Per user | A new evaluation replaces the oldest in-flight one | Not configurable |
| Re-entry window — maximum | 1 year | Per flow | Longer re-entry windows can't be set | Not configurable |
| Business event flows — hourly trigger cap | 5 / hour | Per workspace | Triggers beyond the cap are ignored silently | Contact Support (priced at a 5x cost multiplier) |
| Business event flows — daily trigger cap | 20 / day | Per workspace | Activations beyond the cap are ignored | Contact Support (priced at a 5x cost multiplier) |
| Business event flows — max audience per activation | 10,000,000 | Per activation | Additional users can't enter on that trigger | Not configurable |
| Flow tags — maximum | 5 | Per flow | You can't add more tags | Not configurable |
| Flow name — maximum length | 256 characters | Per flow | Longer names can't be saved | Not configurable |
| Debug Flows lookback — maximum | 7 days | Per flow | You can't search trip history further back | Not configurable |
