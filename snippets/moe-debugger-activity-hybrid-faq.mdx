The MoEngage {props.sdk} SDK bundles the native MoEngage Android SDK, so your Android build includes `MoEDebuggerActivity`, a component that supports on-device SDK debugging. Refer to [What is MoEDebuggerActivity?](/developer-guide/android-sdk/troubleshooting-and-faqs/troubleshooting-and-faqs) to understand what it does. The exclusion steps on that page apply to native Android integrations only — contact MoEngage support if you need to exclude this module from a {props.sdk} build.
