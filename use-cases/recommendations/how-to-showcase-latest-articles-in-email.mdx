# Introduction

Businesses showcase their latest articles to keep subscribers engaged with fresh content as soon as it goes live. This encourages readers to return to your platform by highlighting relevant updates. This use case enables you to automatically pull your most recently published articles and display them in any email campaign, ensuring your audience is always up-to-date.

## Advantages of Showcasing the Latest Articles

- **Automated fresh content**: Your emails always feature the latest articles without any manual updates.
- **Increased engagement**: Presenting timely content keeps your readers interested and encourages more frequent click-throughs.
- **Saved time**: Free up marketing hours by automating what was once a manual process.

You can achieve this use case using the following steps:

1. [Create your Latest Articles Feed using MoEngage Recommendations](#create-your-latest-articles-feed-using-recommendations)
2. [Add the Recommendation Product Set to your Email campaign](#add-the-recommendation-product-set-to-the-email-campaign)

<Note>
  **Prerequisites**

  Ensure your [product catalog](/user-guide/content/recommendations/prerequisites/catalogs) meets the following data requirements before configuring the recommendation:

  - Your catalog must include a *Published Date* attribute to identify the "latest" content. The date format must include the exact time (for example, `2025-08-22T11:49:44Z`). This precision is required to correctly sort articles published on the same day (for example, distinguishing a 3 PM post from a 10 AM post).
  - Your catalog contains the necessary fields such as title, image link, and description to populate the visual elements of the email.
</Note>

# Create your Latest Articles Feed using Recommendations

Perform the following steps to create the latest articles feed using MoEngage Recommendations:

1. Navigate to the MoEngage Dashboard and select **Content** \> **Recommendations** from the left navigation. The Recommendations page is displayed.
2. At the top right corner, click **\+ Create recommendation**. This takes you to the first step, **Select recommendation model**.
3. Select the **Item Attributes** model and click **Next**. For more information, refer to [Item Attribute Model](/user-guide/content/recommendations/basic-recommendations/item-attribute-model).
   <img
     src="/images/latest-articles-select-item-attributes-model.png"
     alt="Select recommendation model step with the Item Attributes model selected"
     style={{ width:"75%" }}
   />
4. In the second step, **Create recommendation**, enter the following details:
   1. **Recommendation name**: Enter a name for the recommendation.
   2. **Recommendation description**: Enter a description for the recommendation. This description helps you understand the model's aim.
   3. **Catalog**: Select the catalog you created earlier, which contains the *Published Date* attribute.
   4. In the **Filter recommendations by item attribute** section, create a filter to only include items where the *Published Date* exists, as shown below:
      <img
        src="/images/latest-articles-filter-published-date-exists.png"
        alt="Filter recommendations by item attribute set to include items where Published Date exists"
        style={{ width:"60%" }}
      />
   5. In the **Sort the filtered items** section, to put the newest articles at the top, configure the sorting logic as below:
      - In the **Order results by** dropdown, select **Published Date**.
      - Select **Order By** as **Descending**.
   6. Click **Create**. You have now created the Latest Articles Feed.

# Add the Recommendation Product Set to the Email Campaign

You can add the recommendation product set to your email campaign and use the *Personalized Preview* feature to view how it is displayed to your user. For more information, refer to [Using Recommendations in Email](/user-guide/content/recommendations/personalize-campaign-with-recommendations/using-recommendations-in-email).
