A Custom Agent works with your MoEngage data through the tools you assign to it. **Connectors** extend that reach to applications outside MoEngage, so a single agent reads a campaign brief from Google Sheets and works with your campaign data in the same run.

<Note>
 Connectors are in a phased beta and are not yet generally available. To ask about joining the beta for your workspace, contact your Customer Success Manager (CSM).
</Note>

## How Connectors Work

- **Selection applies to connectors, not individual tools.** When you add a connector to an agent, every tool that the connector provides becomes available to that agent for the duration of the run.
- **Connectors remain separate from MoEngage tools.** Adding a connector leaves the agent's MoEngage tool assignments unchanged, and you manage the two sets independently. For MoEngage tools, refer to [Assign Tools](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#assign-tools).
- **Each user connects their own account.** A connector authenticates the user who starts the session, so the agent works with that user's data in the external application.

## Available Connectors

The **Connectors** section lists the applications enabled for your workspace. Google Sheets, Google Drive, and Google Calendar are available in the first phase of the beta, and MoEngage enables further applications in later phases.

## Add a Connector to an Agent

The **Connectors** section appears in the Agent Builder once your workspace joins the beta. To give an agent access to an external application:

1. Open the agent in the Agent Builder. For a new agent, refer to [Create a Custom Agent](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#create-a-custom-agent). For an existing agent, go to **Manage** > **Edit** on the agent's detail page.
2. Open the **Connectors** section.
3. Select the application you want the agent to use.
4. Complete the application's sign-in and consent screen. The application then grants MoEngage access to your account.
5. Reference the connector in the agent's instructions: specify which application holds each input, and state what the agent must do with it. For guidance, refer to [Configure your Agent's Instructions](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#configure-your-agents-instructions).
6. Run a **Test agent** session to confirm that the agent reaches the application as expected, and then click **Make live**.

## Authentication at Run Time

MoEngage resolves connector access against the user who starts a session rather than the user who built the agent. When a teammate runs an agent that uses Google Sheets, the agent works with that teammate's Google Sheets account and returns results scoped to it.

Connecting an application during agent configuration allows you to test the agent against your own account. Each teammate who runs the agent connects their own account to the same application. For details on how connector access relates to your MoEngage permissions, refer to [Custom Agent Essentials: Permissions and Security](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/custom-agents-essentials-permission-and-security).

<Warning>
 A connector grants an agent the same access to the external application that you approve on the sign-in and consent screen. Review that screen before you approve it, and connect only the applications an agent requires to complete its task.
</Warning>

## FAQs

<AccordionGroup>
  <Accordion title="Can I choose which tools within a connector an agent uses?">
    Selection applies at the connector level. Once you add a connector to an agent, the agent uses any of that connector's tools that its instructions require. Control the agent's behavior through its instructions and through the connectors you add.
  </Accordion>

  <Accordion title="Does adding a connector change my agent's MoEngage tools?">
    No. Connectors and MoEngage tools form separate sets. Adding, changing, or removing a connector leaves the agent's assigned MoEngage tools unchanged.
  </Accordion>

  <Accordion title="Whose account does a connector use during a run?">
    The account of the user who starts the session. Every connector call in that session authenticates as that user, so each teammate who runs the agent works with their own data in the external application.
  </Accordion>
</AccordionGroup>
