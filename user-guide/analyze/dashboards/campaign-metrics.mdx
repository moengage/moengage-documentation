<Info>

</Info>

## Engagement Rates

| Channel | CTR | CVR |
| --- | --- | --- |
| Email | (Total clicks / Total delivered) × 100 | View-through: (Unique conversions / Unique opens) × 100 <br /> Click-through & In-session: (Unique conversions / Unique clicks) × 100 |
| Mobile Push | (Total clicks / Total impressions) × 100 | View-through: (Unique conversions / Total impressions) × 100 <br /> Click-through & In-session: (Unique conversions / Total clicks) × 100 |
| SMS | (Total Clicked / Delivered) × 100\* | (Number of conversions / Delivered) × 100\* |
| MMS | (Total Clicked / Delivered) × 100\* | (Number of conversions / Delivered) × 100\* |
| RCS | (Total Clicked / Delivered) × 100\* | (Conversions / Delivered) × 100 |
| WhatsApp | Unique Clicks / Delivered × 100 <br /> Click-through-open rate = Unique Clicks / Read | Conversions / Delivered |
| In-App | Clicks / Impressions | Conversions / Impressions |
| On-Site Message | Clicks / Impressions | Conversions / Impressions |
| Web Personalization | Clicks / Impressions | Conversions / Impressions |
| Cards | Not published — only raw counts (Sent, Delivered, Impressions, Click, Conversions) | Not published |
| Connectors | N/A | Conversions / Sent (new UI) — formula is image-only on the old UI page |
| Connected Apps | N/A | Formula is image-only, not text |
| Facebook Audience | Not published on this page | Not published on this page |
| Google Ads Audience | Not published on this page | Not published on this page |

<Note>
  \*For SMS/MMS/RCS campaigns sent using custom connectors where Delivery Tracking is not configured, the denominator switches from Delivered to Sent.
</Note>

## Delivery and Success Rates

| Channel | Formula |
| --- | --- |
| Email | Delivery rate = (Total delivered / Total sent) × 100 <br /> Failed rate = (Failed to Send / Attempted) × 100 <br /> Bounce rate = ((Hard bounces + Soft bounces) / Total sent) × 100 |
| WhatsApp | Delivery rate = % of Sent with a Delivery Receipt received <br /> Read rate = Unique reads / Delivered |
| RCS | Delivery rate = (Delivered / Sent) × 100 <br /> Read rate = (Read / Delivered) × 100 |
| Connectors (new UI) | Sent rate = (Sent / Attempted) × 100 <br /> Failure rate = (Failed / Attempted) × 100 <br /> CVR = (Unique conversions / Total sent) × 100 |
| Connectors (old UI) / Connected Apps | Success Rate and Conversion Rate shown, but the formula is an embedded image, not text |
| Mobile Push | No delivery-rate formula published — Impressions is the closest published metric, and equals Sent when the iOS impressions toggle is off |

## Revenue Metrics

These formulas are consistent across every channel that supports revenue tracking:

- **Average Order Value** = Total Campaign Revenue / Number of conversion events
- **Average Revenue Per (Converted) User** = Total Campaign Revenue / Number of unique conversions
