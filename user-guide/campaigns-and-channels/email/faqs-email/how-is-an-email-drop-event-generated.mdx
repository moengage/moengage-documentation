## Explanation

The _Email Dropped_ event is an internal MoEngage event recorded only for event-triggered and flow email campaigns. During delivery, MoEngage drops a send and generates this event when:

1. The user's unsubscribe, spam, or bounce attribute is true.
2. The user's email address is missing, or the email attribute set in the campaign is invalid.

<Info>
  The _Email Dropped_ event is specific to MoEngage.
</Info>

## Why One-Time and Periodic Campaigns Show 0

MoEngage evaluates these drop conditions for every campaign, but at different stages:

- For event-triggered and flow campaigns, evaluation happens at the time of delivery, so MoEngage raises an _Email Dropped_ event against each user profile it drops.
- For one-time and periodic campaigns, MoEngage filters out users who meet these conditions earlier, while evaluating the target audience. Those users are removed before delivery, so no separate _Email Dropped_ event is raised.

A count of 0 for the _Email Dropped_ event on a one-time or periodic campaign is therefore expected behavior, not a bug.
