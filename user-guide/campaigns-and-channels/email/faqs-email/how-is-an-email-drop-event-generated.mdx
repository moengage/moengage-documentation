## Explanation

The _Email Dropped_ event is an internal MoEngage event recorded only for event-triggered and flow email campaigns. During delivery, MoEngage drops a send and generates this event when:

1. The user's unsubscribe, spam, or bounce attribute is true.
2. The user's email address is missing, or the email attribute set in the campaign is invalid.

<Info>
  The _Email Dropped_ event is specific to MoEngage.
</Info>

## Why One-Time and Periodic Campaigns Show 0

MoEngage checks these drop conditions for every campaign — it just does so at different points:

- In event-triggered and flow campaigns, the check runs when the email is about to be sent. Any user who fails the check is dropped at that moment, and MoEngage records an _Email Dropped_ event for them.
- In one-time and periodic campaigns, MoEngage runs the same check earlier, while building the target audience. These users are removed before sending starts, so there is no send to drop — and no _Email Dropped_ event is recorded.

This is why a one-time or periodic campaign shows 0 for the _Email Dropped_ event. It is expected, not an error.
