---
title: "How to Segment Users Who Complained About Spam?"
description: "Step-by-step instructions for creating a segment of users who reported an email as spam, so you can suppress them or investigate the campaigns driving complaints."
---

If you need to isolate users who marked one of your emails as spam — for suppression, list hygiene, or investigating a spike in complaints — you can build this as a **User Behavior** segment based on the **Email Spam Complained** event.

## Steps

1. Go to **Segment** in the left sidebar, then click **+ Create New** (or **+ New Segment**) to open the **Create segment** page.

2. Select **Filter users by**, then click the **User behavior** tab (next to **User property**, **User affinity**, and **Custom segment**).

3. In the first dropdown, leave the condition as **Has Executed**, then select **Email Spam Complained** from the event dropdown.

   ![Create segment page with User behavior tab selected and the Email Spam Complained event chosen](/images/segment-email-spam-complained.png)

4. Set how many times and over what period the event should have occurred:
   * Choose a frequency comparator (e.g., **at least**) and enter the number of times (e.g., **1**).
   * Choose a time window (e.g., **in the last 3 days**) — increase this if you want to capture complaints going further back.

5. **(Optional)** Narrow the segment to complaints tied to a specific campaign or condition:
   * Click **+ Attributes**.
   * Select an attribute, such as **Readable Campaign Id**, from the dropdown.
   * Set the condition (e.g., **is**) and search for or select the value in the **Select Option** field.

6. **(Optional)** Add more rules or refine the segment further:
   * Click **+ Filter** to add another condition (combine with AND/OR).
   * Check **Exclude Users** if you want to use this as an exclusion rule instead of an inclusion rule (for example, to exclude spam complainers from a campaign's target audience).
   * Click **+ Nested Filter** to group conditions.

7. Click **Show count** to preview how many users currently match this segment before saving.

8. Name and save the segment once you're satisfied with the criteria.

## Using the same steps for bounces and unsubscribes

The **User behavior** tab lists other email-hygiene events alongside **Email Spam Complained** — including **Email Bounced**, **Email Soft Bounced**, and **Email Unsubscribed**. You can build the equivalent segment for either of these by repeating the same steps and swapping the event in step 3:

* For hard bounces, select **Email Bounced**.

  ![Create segment page with the Email Bounced event selected](/images/segment-email-bounced.png)

* For unsubscribes, select **Email Unsubscribed**.

  ![Event dropdown open, showing Email Unsubscribed and other available email events](/images/segment-email-unsubscribed-event-list.png)

Other related events available in the same dropdown include **Email Resubscribed**, **Email Subscription Category Updated**, **Email Unsubscribe Drop**, and **Email Opt-in Status Updated** — useful if you want to build segments around re-engagement or preference changes instead of suppression.

## What this segment is useful for

* **Suppression / list hygiene:** Use the segment (with **Exclude Users**) to keep recent spam complainers, bounces, or unsubscribes out of upcoming campaigns.
* **Root-cause investigation:** Narrow by **Readable Campaign Id** to check whether complaints are concentrated around a specific send, so you can review its content, frequency, or targeting.
* **Compliance reporting:** Track complaint volume over a rolling window (e.g., last 3, 7, or 30 days) to monitor whether your complaint rate is trending toward mailbox provider thresholds.
