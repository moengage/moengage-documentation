# Campaign Analytics

<Info>
  All the metrics are calculated and displayed in the App's Timezone.
</Info>

The campaign analytics section has the following information:

| Field | Description |
| --- | --- |
| Eligible users | This is the number of users who have qualified for the campaign based on their having fulfilled the segmentation criteria and trigger criteria, if applicable. |
| Attempted | This is the number of eligible users who have at least one of the identifiers that the campaign passes to Facebook - Device Identifier (Device ID) or Customer Match Identifiers (Mobile Number, Email). Only these users can be synced. A user being reachable on another channel (such as push) does not make them an attempted user - if they do not have at least one of these identifiers, MoEngage cannot send them to Facebook, so they are not counted here. |
| Successfully synced | This is the number of users from the list of attempted users that were added to the Facebook console. |
| Conversions | This represents the unique number of successfully synced users who have received the conversion event during the attribution window. |
| Conversion events | This represents the number of successfully synced users who have received the conversion event during the attribution window. |

<Note>
  Conversion Goal is optional during campaign creation. The above conversion-related metrics are measured and displayed if it is added during campaign creation.
</Note>

<Note>
  Successfully synced is confirmed at the batch level. MoEngage sends users to the Facebook console in batches, and Facebook confirms the batch was received. Some individual users within a confirmed batch may be dropped during Facebook's internal processing without being reported back, so this metric may not reflect those individual drops.
</Note>

<Note>
  It takes between 6 and 48 hours for Facebook audiences to sync in the Facebook ad center.
</Note>

The metrics in the above table are available for all delivery types.

### Campaign Analytics for Periodic Campaigns

In the case of a periodic campaign, the above stats are available for the parent campaign. The stats for the child campaigns (every instance of the campaign run) are shown in a table below these stats.

## Campaign Stats Filters

These filters are available only for periodic and event-triggered campaigns.

1. **Aggregation Type**: You can choose Total/Average here.
2. **Date Range**: You can choose the date range for which you want to see the information about the campaign instances.

The campaign failure breakdown section will list the errors or failures encountered while running the campaign. These could be access-related errors, data-related failures, or API/service-related failures, which are listed below.

For more information on understanding these errors, refer to [Troubleshoot common errors in FB Audience](/user-guide/campaigns-and-channels/facebook-audience/troubleshooting-and-faqs-facebook-audience/troubleshoot-common-errors-in-fb-audience).

# Campaign Info

The campaign info tab has the following information:

| Field | Description |
| --- | --- |
| Segmentation | This section contains information about the target segment chosen for the campaign. |
| Qualification Criteria | This section contains information about the filters and criteria that the users in the target segment need to satisfy to qualify for the campaign. |
| Facebook audience | This section contains information on whether the audience will be added to or removed from the custom audience. |
| Goals | This section contains information about the goals set for the campaigns. |
| Timing | This section contains information about the campaign's delivery schedules, including the start and end times of the campaign instance. |
