When you set up Facebook Audience campaigns using Marketing APIs, you might run into specific errors. Below are some common errors and how to resolve them.

| Requires business\_management permission | Your app needs the **business\_management** permission to read and write with the Facebook Business Manager API. This permission is needed to manage business assets, such as an ad account. You may also use this permission to request analytics insights to improve your app and for marketing or advertising purposes through the use of aggregated and de-identified or anonymized information (provided such data cannot be re-identified). | Generate a new access token that includes the **business\_management** permission, then reconnect Facebook Audience in MoEngage. Please try again. | This error appears when you cannot create a new custom audience during Step 2 of Facebook Audience Campaign creation. | One common reason for this is that the Facebook Custom Audience terms have not been accepted for your ad account. ## Resolve the business_management permission error

If the Facebook Audience sync fails because your access token is missing the **business_management** permission, generate a new token that includes this permission using the Graph API Explorer, and then extend it to a long-lived token.

1. Open the [Graph API Explorer](https://developers.facebook.com/tools/explorer).
2. From the **Meta App** drop-down, select your app.
3. From the **Permissions** drop-down, make sure **ads_read**, **ads_management**, and **business_management** are all selected. `business_management` is the permission commonly missing that causes this error.
4. Click **Generate Access Token**. <img alt="Graph API Explorer with the business_management permission selected and the Generate Access Token button" src="/images/facebook-graph-api-explorer.png" />
5. The generated token is short-lived. To extend it, open the [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken).
6. Paste the token, and then click **Extend Access Token** to generate a long-lived token that is valid for 60 days. <img alt="Access Token Debugger showing a short-lived token and the Extend Access Token button" src="/images/facebook-access-debugger.png" />
7. Copy the extended token, and then use it to [connect Facebook Audience in MoEngage](/user-guide/campaigns-and-channels/facebook-audience/getting-started-with-facebook-audience/facebook-audience-settings-on-moengage-dashboard).

## Check for Required Permissions

Facebook's API does not let you create or change Custom Audiences if the terms have not been accepted. If the contract is not signed, Facebook triggers an error when you try to create or edit a Custom Audience.

## Identify Permission Issues

To confirm that permission issues are causing the audience creation failure, follow these steps:

1. Go to **Developer Tools** in your browser.
2. Select the **Network** tab.
3. In MoEngage, click **Create Audience** in the **Create new audience** section.
4. Look for the error message that appears in the Network tab, as shown below.

### Resolve Permission Issues

To resolve this issue, follow these steps:

1. Navigate to the [Manage Custom Audiences](https://www.facebook.com/login/?next=https%3A%2F%2Fwww.facebook.com%2Fads%2Fmanage%2Fcustomaudiences%2Ftos.php) page on Facebook. You might be asked to log in if you are not already logged in.
2. Update the correct Ad account ID in the URL.
3. Accept the terms and conditions for the Ad account.
4. Fetch a new access token from the [Facebook App dashboard](https://developers.facebook.com/apps).
5. Go to the MoEngage dashboard. Log out from Facebook on the MoEngage **Settings** page, and then log in again with the new access token.
6. Try creating a new audience or adding new users to an existing audience.

If the problem continues, try these additional steps:

1. Go to the [Facebook App dashboard](https://developers.facebook.com/apps), and then click **Add Product**.
2. Search for **Facebook Login**, and then select it.
3. Fill in the relevant details. This should add **Facebook Login** to the left panel under **Products**.
4. Return to the MoEngage dashboard, and then try creating a new audience or adding new users to an existing audience.
