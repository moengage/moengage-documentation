Common questions about mobile push. For issues and fixes, see [Troubleshoot Mobile Push](/user-guide/campaigns-and-channels/mobile-push/troubleshoot-mobile-push).

<AccordionGroup>
  <Accordion title="Can GIFs be used in push campaigns?">
    GIFs aren't supported in push notifications on Android. They are supported on iOS push notifications. If you need GIF support on Android, raise a [feature request](/user-guide/contact-support/suggest-a-feature).
  </Accordion>
  <Accordion title="What are the limitations of Push Amplification™ Plus?">
    Push Amplification™ Plus improves push delivery rates by up to 40%, but has some limitations.

    **SDK compatibility** — available from these SDK versions onward:

    | Android SDK type | Push Amplification™ Plus support on Huawei |
    | --- | --- |
    | Native Android SDK | 10.3.00 and above |
    | React Native | 6.0.0 and above |
    | Segment Integration SDK | 4.2.00 and above |
    | Flutter | 2.0.0 and above |
    | Cordova | 6.0.0 and above |
    | Unity | Not available |
    | Xamarin | Not available |

    **Limitations of the direct delivery service** (these don't apply to the fallback service):

    - No fallback mechanism (the direct service already delivers at 75–95%).
    - No custom display where the app parses key-value pairs or the MoEngage payload.
    - Character limits: title 40 characters, message 1,024 characters (including spaces).
    - No notification image support (small and large app icons are supported).
    - No data payloads.
    - No customized notification channels — use a custom channel or the MoEngage default; unlike FCM, the default won't act as a fallback for HMS if setup is incorrect.
    - No customizing notification message icons.
    - The *Notification Cleared* event isn't tracked; the Notification Center shows only clicked notifications; notification received and clear callbacks don't fire; push templates don't work (basic notifications only); display customization via key-value pairs doesn't work.
  </Accordion>
</AccordionGroup>
