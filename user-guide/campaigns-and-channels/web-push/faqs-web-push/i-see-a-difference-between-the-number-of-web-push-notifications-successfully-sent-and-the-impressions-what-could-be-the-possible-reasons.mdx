---
title: "I see a difference between the number of web push notifications Successfully Sent and the Impressions.  What could be the possible reasons?"
description: "Why web push impression counts may be lower than sent counts, including reasons like user offline status, browser state, and communication failures."
---

The number of web push notifications that MoEngage successfully passes to Firebase Cloud Messaging (FCM) is what you see as Successfully Sent.

Impressions are the number of notifications that reach the user.

There may be instances when Impressions are lower than Successfully Sent.

The following factors contribute to this difference:

- The user does not come online before the notification expires.
- The browser does not run on the user's device.
- Communication between FCM, the browser, and the operating system fails.

<Note>
Operating system settings do not contribute to this difference. When a user grants web push permission in the browser but turns off notifications for that browser at the operating system level, the browser receives the notification, so MoEngage counts the impression and tracks the *Notification Received Web* event, even though the operating system suppresses the on-screen display. MoEngage also counts this user as subscribed and reachable for web push. For more information, refer to [Browser Permission Versus OS-Level Notification Settings](/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/web-push-permission-and-reachability#browser-permission-versus-os-level-notification-settings).
</Note>

Funnel-wise analysis right from the stage you select your target users till the stage the users get the web push notifications is available under the Campaign Reports.
