Use the HTML editor to build a landing page from your own HTML instead of the drag-and-drop editor. This is useful when you already have a landing page designed in another tool and want to bring it into MoEngage as-is. Unlike the [Embed element](/user-guide/content/landing-pages/create/landing-page-editor#content), the HTML editor gives you a full editing area and a live preview of your page.

You can add your HTML in one of two ways:

- **Paste custom HTML** directly into the editor.
- **Upload an HTML ZIP file** that contains your page and its assets.

After you add your HTML, preview the landing page before publishing.

# Create a Landing Page from HTML

{/* TODO: confirm the exact entry point and step labels once the UI is final. */}

1. On the left navigation menu, click **Content**, and then click **Landing pages**.
2. Click **Create a landing page** and define the page name and tags.
3. In the **Content** step, choose the HTML editor.
4. Add your page by either pasting your custom HTML or uploading an HTML ZIP file.
5. Preview the page to confirm it renders as expected.
6. Publish the landing page.

# Make the Page Interactive

To track clicks, capture form submissions, or read and write email subscription categories from a custom HTML landing page, use the MoEngage JavaScript bridge. For the available methods and examples, see [JavaScript Bridge for On-Site Messaging and Landing Pages](/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-on-site-messaging-and-landing-pages).

To build a subscription preference center on a custom HTML page, see [Manage Subscription Preferences with Landing Pages](/user-guide/content/landing-pages/create/manage-subscription-preferences#use-a-fully-custom-html-landing-page).
