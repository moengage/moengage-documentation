title: "Manage Recommendations"
description: "Edit, archive, or restore basic recommendations from the MoEngage listing page. Update configurations and monitor recommendation statuses easily."
---

On the Recommendations page, you can manage the created recommendations. The status of the recommendations is shown on the listing page itself. You can edit, archive, or unarchive a recommendation.

# Edit Recommendations

To edit a recommendation, perform the following steps:

1. On the sidebar menu in MoEngage, hover over the Content menu item <img alt="content icon.png"  src="/images/moengage_74beb9.png"  /> . The **Content** menu appears.
2. Click **Recommendations**.   
    <img  src="/images/moengage_8bda2f.png"  />   
   The Recommendations page appears.
3. Click the pencil icon for the required recommendation to edit it. The Edit Recommendation page is displayed.  
    <img src="/images/moengage_04e53e.png" />
4. Choose the configuration you want to update, make the desired changes, and click **Save** at the bottom of the page.

We encourage you to test the results for a few sample users before saving any changes.

# Archive or Unarchive

You can disable an active recommendation on the Recommendations page by clicking the **Archive** icon in the **Actions** column. <img src="/images/moengage_ba58a4.png" />

You can enable an archived recommendation by clicking the **Unarchive** icon in the **Actions** column. <img src="/images/moengage_3be281.png" />

<Note>
  Archived recommendations do not return any results. Any active campaign referencing an archived recommendation displays no items. To prevent this, ensure a fallback is configured in your campaigns.
</Note>

# Test a Recommendation

Before using this recommendation in a campaign, test it against a real user, a random sample, or a specific item. For more information, refer to [Test a Recommendation](/user-guide/content/recommendations/getting-started/test-a-recommendation).
