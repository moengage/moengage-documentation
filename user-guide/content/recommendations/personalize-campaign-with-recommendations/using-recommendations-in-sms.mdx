Add recommendations to your SMS campaigns to send each user a product that matches their interests instead of the same message to everyone. In SMS, recommendations go into the message text using the [Jinja templating language](/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language).

At MoEngage, creating an SMS campaign is a three-step process.

1. Target users
2. Content
3. Schedule and Goals

You can personalize the campaign with recommendations in the second step 'Content'. Let us create a recommendation personalized SMS campaign.

<Warning>
  Ensure that you have created the desired recommendations. You can use only active recommendations for campaign personalization. Learn how to [create and manage recommendations](/user-guide/content/recommendations).
</Warning>

<Note>
  SMS has a limited character count. A product set on its own inserts every item in the set, which can split the message into multiple SMS. Modify the Jinja code to fetch a single item, as described in step 10. The character count and the number of SMS appear below the preview.
</Note>

# Create SMS Campaigns with Recommendations

To create an SMS campaign with recommendations, perform the following steps:

1. On the sidebar menu in MoEngage, hover over the Engage menu item <img alt="The Engage menu icon" src="/images/moengage_3a6ded.png" style={{ display: "inline-block", height: "20px", width: "auto" }} /> . The **Engage** menu appears.
2. Click **+ New Campaign**. <img src="/images/moengage_f884be.png" alt="The Engage menu with the New Campaign option" /> You can also click **All Campaigns** on the **Engage** menu and then click **\+ Create campaign** on the All campaigns page.
3. On the **New Campaign** dialog box, under **OUTBOUND**, click **SMS**.
4. Click **Periodic**. The same steps apply to any other SMS campaign type. For more information, refer to [Delivery Types](/user-guide/campaigns-and-channels/getting-started/introduction/delivery-types-moengage-channels).
5. In step 1 'Target users', enter the campaign details, define the audience, and click **Next**.
6. In step 2, on the **Content** tab, click **Blank Template** under **Default templates**, or select a template under **Custom templates**.
7. Select the sender in the **SMS sender** list.
8. In the **Message** field, type '@' where you want the recommendation to appear. The **SMS Personalization** window opens.
9. On the **Data personalization** tab, in the **Select attribute** list, search for your recommendation and select it under **Product sets**. Under **Choose Fallback**, select a fallback and click **Done**.
   The **Choose Fallback** option controls what a user receives when personalization fails for them:

   | Fallback | What happens |
   | --- | --- |
   | **No fallback** | The recommendation is replaced with an empty value. |
   | **Do not send SMS** | The SMS is not sent to that user. |
   | **Replace text** | The recommendation is replaced with the text you enter. |
10. It auto-populates some Jinja code retrieving all available items list from recommendations. You can modify the code for your use case. For example, the following is the modified code to display one item:
    <CodeGroup>
    ```jinja Item Title
    {% if ProductSet.Recommendations %}
    {% for product in ProductSet.Recommendations[0:1] %}
    {{product.title}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```

    ```jinja Item Link
    {% if ProductSet.Recommendations %}
    {% for product in ProductSet.Recommendations[0:1] %}
    {{product.link}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```
    </CodeGroup>
    <Note>
      `MOE_NOT_SEND` stops the message from going out when the product set is empty for a user, so no one receives an SMS with a missing product.
    </Note>
11. To display an item attribute, place the cursor inside the `for` loop, type '@', and select the attribute in the **Select attribute** list. The attribute is inserted inside the loop, for example `{{product['price']}}`.
12. Repeat steps 8 to 11 for each remaining recommendation. You can mix recommendations with static text.
13. Under **Preview type**, click **Personalized** to check the message with real values.
14. Deliver a test campaign to check end-to-end delivery before you schedule it for all users. (Optional) <img src="/images/moengage_64d866.png" alt="The Test Campaign panel" />
15. Click **Next** to move to step 3 'Schedule and Goals'.
16. Configure **Schedule and Goals** and publish the campaign.
