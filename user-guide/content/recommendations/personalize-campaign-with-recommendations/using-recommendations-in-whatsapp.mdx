By adding recommendations to your WhatsApp campaigns, you can send each user the products most relevant to them instead of the same message to everyone. In the WhatsApp channel, recommendations are inserted into the placeholders of a pre-approved WhatsApp template using the [Jinja templating language](/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language).

At MoEngage, creating a WhatsApp campaign is a three-step process.

1. Target users
2. Content
3. Schedule and Goals

You can personalize the campaign with recommendations in the second step 'Content'. Let us create a recommendation personalized WhatsApp campaign.

<Warning>
  Ensure that you have created the desired recommendations. You can use only active recommendations for campaign personalization. Learn how to [create and manage recommendations](/user-guide/content/recommendations).
</Warning>

# Prerequisites

Unlike Email and Push, WhatsApp requires an approved template before you can personalize content. Ensure the following:

- A recommendation (product set) is set up and mapped to a user action. Refer to [Map User Actions Settings](/user-guide/content/recommendations/prerequisites/map-user-actions-settings).
- You have a pre-approved WhatsApp template with enough placeholders to hold the recommendation data. For example, to send a user's name plus a recommended product's title and link, get a template approved with three placeholders. Refer to [WhatsApp Templates](/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates).

# Create WhatsApp Campaigns with Recommendations

To create a WhatsApp campaign with recommendations, perform the following steps:

1. On the sidebar menu in MoEngage, hover over the Engage menu item <img alt="The Engage menu icon" src="/images/moengage_3a6ded.png" style={{ display: "inline-block", height: "20px", width: "auto" }} /> . The **Engage** menu appears.
2. Click **+ New Campaign**. <img src="/images/moengage_f884be.png" alt="The Engage menu with the New Campaign option" /> You can also click **All Campaigns** on the **Engage** menu and then click **\+ Create campaign** on the All campaigns page.
3. On the **New Campaign** dialog box, under **MESSAGING APPS**, click **WhatsApp**.
4. Click **Periodic** campaign, and you can follow the same steps for any other WhatsApp campaign type. For more information about delivery types, refer to [Delivery Types](/user-guide/campaigns-and-channels/getting-started/introduction/delivery-types-moengage-channels). <img src="/images/whatsapp-new-campaign-periodic.png" alt="The New Campaign dialog box with WhatsApp selected under Messaging Apps and the Periodic delivery type" />
5. Enter the basic campaign details and define the audience in step 1 'Target users' and click **Next**.
6. In step 2, on the **Content** tab, select the sender in the **Select sender** list.
7. Select the approved template in the **Select template** list. <img src="/images/moengage_6b5913.png" alt="Selecting the sender and the approved template on the Content tab" />
8. In the **Header** or **Body** placeholder field, type '@'. The **WhatsApp Personalization** window opens.
9. On the **Data personalization** tab, in the **Select attribute** list, search for your recommendation and select it under **Product sets**. <img src="/images/moengage_86260a.png" alt="The WhatsApp Personalization window showing the Data personalization tab and the Choose Fallback options" />
10. Under **Choose Fallback**, select a fallback and click **Done**.
    The **Choose Fallback** option controls what a user receives when personalization fails for them:

    | Fallback | What happens |
    | --- | --- |
    | **No fallback** | The placeholder is replaced with an empty value. |
    | **Do not send campaign** | The campaign is not sent to that user. |
    | **Replace text** | The placeholder is replaced with the text you enter. |
11. It auto-populates some Jinja code retrieving all available items list from recommendations. You can modify the code for your use case. For example, the following is the modified code to display one item:
    <CodeGroup>
    ```jinja JINJA
    {% if ProductSet.RealTimeAIRecommendations%}
    {% for product in ProductSet.RealTimeAIRecommendations[0:1]%}
    {{product.title}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```
    </CodeGroup>
    <Note>
      `MOE_NOT_SEND` stops the message from going out when the product set is empty for a user, so no one receives a message with a blank placeholder.
    </Note>
12. To display an item attribute, place the cursor inside the `for` loop, type '@', and select the attribute in the **Select attribute** list. The attribute is inserted inside the loop, for example `{{product['price']}}`.
13. Repeat steps 8 to 12 for each remaining placeholder in the template. You can choose recommendations personalization or static textual content for different placeholders.
14. After you complete the setup, under **Preview type**, click **Personalized**. MoEngage selects a user and renders the message with real values.
15. To preview the message for a specific user, click the edit icon <img alt="The edit icon" src="/images/personalized-preview-edit-icon.png" style={{ display: "inline-block", height: "16px", width: "auto" }} /> . The **Personalized preview** slide-out opens.
16. In the **Select user by** list, select the identifier you want to use.
17. In the **User identifier value** field, type the identifier of the user.
18. Click **Fetch user data**. Under **Personalization inputs**, your product set appears as JSON with the items available for that user.
19. Change the JSON to match what you want to preview. (Optional)
20. Click **Update preview**. <img src="/images/whatsapp-personalized-preview.png" alt="The Personalized preview slide-out showing the product set JSON and the rendered message" />
    <Note>
      To enable **Update preview** for your account, contact your MoEngage CSM or the Support team. For more information, refer to [Personalized Preview](/user-guide/campaigns-and-channels/getting-started/message-personalization/personalized-preview).
    </Note>
21. You can also deliver a test campaign to ensure end-to-end delivery before scheduling it for all users. <img src="/images/moengage_64d866.png" alt="The Test Campaign panel" />
22. After you complete the content setup with recommendations, click **Next** at the bottom and move to 'Schedule and Goals', which is the step 3 of campaign setup.
23. Set up the appropriate settings in **Schedule and Goals** and publish the campaign.
