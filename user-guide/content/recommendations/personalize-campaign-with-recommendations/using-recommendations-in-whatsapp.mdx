By adding recommendations to your WhatsApp campaigns, you can send each user the products most relevant to them instead of the same message to everyone. In the WhatsApp channel, recommendations are inserted into the placeholders of a pre-approved WhatsApp template using the [Jinja templating language](/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language).

At MoEngage, creating a WhatsApp campaign is a three-step process.

1. Target users
2. Content
3. Schedule and Goals

You can personalize the campaign with recommendations in the second step 'Content'. Let us create a recommendation personalized WhatsApp campaign.

<Warning>
  Ensure that you have created the desired recommendations. You can use only active recommendations for campaign personalization. Learn how to [create and manage recommendations](/user-guide/content/recommendations).
</Warning>

# Prerequisites

Unlike Email and Push, WhatsApp requires an approved template before you can personalize content. Ensure the following:

- A recommendation (product set) is set up and mapped to a user action. Refer to [Map User Actions Settings](/user-guide/content/recommendations/prerequisites/map-user-actions-settings).
- You have a pre-approved WhatsApp template with enough placeholders to hold the recommendation data. For example, to send a user's name plus a recommended product's title and link, get a template approved with three placeholders. Refer to [WhatsApp Templates](/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates).

# Create WhatsApp Campaigns with Recommendations

To create a WhatsApp campaign with recommendations, perform the following steps:

1. On the sidebar menu in MoEngage, hover over the **Engage** menu item <img alt="The Engage menu icon" src="/images/moengage_3a6ded.png" style={{ display: "inline-block", height: "20px", width: "auto" }} />. The **Engage** menu appears.
2. Click **+ New Campaign**.

   ![The New Campaign button on the Engage menu](/images/moengage_f884be.png)
3. On the **New Campaign** dialog box, under **OUTBOUND**, click **WhatsApp**.
4. Click **Periodic** campaign.
5. Enter the basic campaign details, define the audience in step 1 'Target users', and click **Next**.
6. In step 2, on the **Content** tab, select the **Sender** with whom the recommendations template was approved.
7. Select the approved template.
8. In a placeholder field, type **@** where you want the recommendation to appear.
9. Search the recommendation name under the **Data personalization** drop-down, and then click **Done**.

   ![The personalization pop-up showing the Data personalization drop-down](/images/moengage_86260a.png)
10. Repeat steps 8 and 9 for each remaining placeholder.
11. Modify the inserted Jinja code to fetch a single item.
12. Click **Personalized preview** to see the message as a specific user receives it.

    ![WhatsApp campaign content step with recommendation placeholders filled in](/images/moengage_6b5913.png)
13. Deliver a test campaign to confirm end-to-end delivery.
14. Click **Next** to move to step 3 'Schedule and Goals'.
15. Set up the appropriate settings and publish the campaign.

You can follow the same steps for any other WhatsApp campaign type. For more information about delivery types, refer to [Delivery Types](/user-guide/campaigns-and-channels/getting-started/introduction/delivery-types-moengage-channels).

Each placeholder in the approved template holds one value, so get a template approved with enough placeholders for everything you want to send.

Typing **@** opens a personalization pop-up. Adding a product set on its own inserts every item in the set, so modify the Jinja to fetch only what you need.

# Fetch a Single Recommended Item

To display one item instead of the whole set, loop through the product set in the placeholder. The following example uses a product set named `ProductSet` with a recommendation named `Recommendations`.

To fetch the title of the first recommended item:

<CodeGroup>
```text JINJA
{% if ProductSet.Recommendations %}
{% for product in ProductSet.Recommendations[0:1] %}
{{product.title}}
{% endfor %}
{% else %}
MOE_NOT_SEND
{% endif %}
```
</CodeGroup>

To fetch the link of the same item in another placeholder:

<CodeGroup>
```text JINJA
{% if ProductSet.Recommendations %}
{% for product in ProductSet.Recommendations[0:1] %}
{{product.link}}
{% endfor %}
{% else %}
MOE_NOT_SEND
{% endif %}
```
</CodeGroup>

`MOE_NOT_SEND` stops the message from going out when the product set is empty for a user, so no one receives a message with a blank placeholder.

A product set contains a list of items, each with attributes such as `name`, `title`, `id`, and `image link`. To fetch an attribute inside the loop, type **@** and select the property from the personalization window.
