# Introduction

[Amazon Redshift](https://aws.amazon.com/redshift/) is a fast and powerful, fully managed, petabyte-scale data warehouse service that forms part of the larger cloud-computing platform Amazon Web Services.

# MoEngage `<>` Redshift

The MoEngage and Redshift integration exports Campaign Interaction Events data directly to your Amazon Redshift cluster.

# Integration

<Tip>
  - Ensure you have an Amazon Web Services account with permission to create/edit Redshift clusters, roles, and policies. 
  - Optional: To create a new user, you need to have access to create a new user in your Redshift Cluster. 
  - If your system requires IP whitelisting, refer [here](https://moengage.com/docs/user-guide/settings/account/security/ip-whitelisting-in-moengage) before setting up the Redshift exports integration.
</Tip>

Read our [Amazon Redshift](https://partners.moengage.com/hc/en-us/articles/11469864792212-Amazon-Redshift) to set up MoEngage `<>` Amazon Redshift integration for your account.
