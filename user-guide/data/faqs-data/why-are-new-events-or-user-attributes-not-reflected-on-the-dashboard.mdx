---
title: "Why Are New Events or User Properties Not Reflected on the Dashboard?"
description: "Fix missing events or user properties on the MoEngage dashboard. Check data management settings, blocked attributes, and event limits to resolve this."
---

## Problem

New events or user properties sent through S2S API calls or SDK requests do not appear on the dashboard.

## Solution

Perform the following steps:

1. Check the data management settings (**Settings** \> **Data Management**). Ensure the event or user property is not blocked or hidden in the settings. If you do not have access to Data Management, contact your admin or manager for assistance.
2. Check event/user property limit. Verify in the data management settings that you haven’t exceeded the event or user property limit.

<Info>
If the event or user property limit is exceeded, you can block unused event or user properties to make space for new attribute ingestion, or contact your CSM to know more about getting your limits extended.
</Info>

For more information, read [Overview - Data Management](/user-guide/settings/data-management/overview-data-management).
