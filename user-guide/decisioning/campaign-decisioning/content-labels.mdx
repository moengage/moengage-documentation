# Overview

Content Labels are the vocabulary that AI Campaign Decisioning uses to understand your message copy. Each message variation you write is labeled against this vocabulary, so the AI can learn which kind of content works for each user.

Content Labels have two parts:

- **Label Category** — a theme, such as "Message Tone".
- **Label** — a value within a category, such as "Playful".

You can manage Content Labels under **Settings → Advanced settings → Content Labels**. The page has two tabs: **Label category** and **Labels**.

<Info>
Content Labels are the vocabulary; [Content Intelligence](/user-guide/decisioning/campaign-decisioning/content-intelligence) is where MoEngage applies that vocabulary to your message variations automatically.
</Info>

# How Content Labels Work

- The hierarchy is single-level: Label Categories contain Labels, with no sub-levels.
- A category can hold up to 20 labels.
- Each label belongs to one category only.
- Each label has a **weight** from -100 to +100 (default 0) that signals its relative importance to decisioning.
- Content Labels are separate from campaign tags and are not shared, to avoid confusion between the two.

MoEngage provides a set of out-of-the-box Label Categories to start from — **Incentives**, **Message Tone**, **User Motivation**, and **Platform Benefits** — each with predefined labels. You can also create your own categories and labels.

# Create a Label Category

<Steps>
  <Step title="Open Content Labels">
    Go to **Settings → Advanced settings → Content Labels** and select the **Label category** tab.
  </Step>
  <Step title="Start a new category">
    Click **+ New Category**.
  </Step>
  <Step title="Enter the category details">
    - **Category name** (required, up to 32 characters).
    - **Category description** (required) — describe what this category represents so labeling stays consistent.
  </Step>
  <Step title="Add labels to the category">
    In the **Add label** section, enter a **Label name** and a **Label description** for each label. Click **+ Add new label** to add more.
  </Step>
  <Step title="Save">
    Click **Save**. The category appears in the **Label category** list with its labels.
  </Step>
</Steps>

# Create a Label

<Steps>
  <Step title="Open the Labels tab">
    Go to **Settings → Advanced settings → Content Labels** and select the **Labels** tab.
  </Step>
  <Step title="Start a new label">
    Click **+ New Label**.
  </Step>
  <Step title="Enter the label details">
    - **Label name** (required, up to 32 characters).
    - **Category** (required) — select the category this label belongs to.
    - **Label description** (required) — describe what the label means.
    - **Examples** (optional) — sample phrases the label applies to.
    - **Label weight** (required) — set the weight using the slider, from **Low (-100)** through **Neutral (0)** to **High (100)**.
  </Step>
  <Step title="Save">
    Click **Save**. The label appears in the **Labels** list with its category, description, examples, and weight.
  </Step>
</Steps>

# Edit and Manage Content Labels

In Phase 0, you can edit some fields but not others:

| Action | Category | Label |
| --- | --- | --- |
| Edit description | Yes | Yes |
| Edit examples | — | Yes |
| Edit weight | — | Yes |
| Rename | No | No |
| Change the category a label belongs to | — | No |
| Delete or archive | No | No |

<Note>
For periodic campaigns, changes to a label's weight, description, or examples take effect from the next run onward.
</Note>
