A Campaign Decisioning Policy defines what the AI optimizes for and the guardrails that it follows. It contains the reward event, performance metrics, eligible audience, send limits, and control group.

<Info>
Users with the required policy permissions can create policies. You can also define a custom role with permissions to create and manage policies.
</Info>

# Terms to Know

| Term | Description |
| --- | --- |
| Reward event | The single User Behavior Event that the policy optimizes for, such as Product purchased. |
| Performance metrics | Additional events tracked as positive or negative signals to measure how the policy performs against the control group. |
| Eligibility | The audience that the policy can send to. At send time, the policy audience is intersected with the campaign audience. |
| Policy control group | A random sample of eligible end users held back from the policy campaigns and used as a baseline to measure impact. |

# Create a Policy

In the MoEngage dashboard, click **Decisioning**, and then click **Campaign decisioning policy**. On the **Campaign decisioning policy** page, click **+ Create policy**.

Creating a policy contains two steps: Goals and Controls.

## Goals

Perform the following steps to configure Goals.

1. Enter the following basic details:
   - **Policy name**. This field is required.
   - **Purpose**. This field is optional. It is a short description shown when marketers select the policy during campaign creation.
   - **Reward event**. This field is required. Each policy has exactly one reward event.
2. In the **Performance metrics** section, configure the metrics that are measured against your control group:
   - Metrics are split into Positive and Negative.
   - Metrics are grouped under Reward event, Brand engagement, Message interactions, and Custom metrics.
   - **App/site opened** is included by default under Brand engagement and cannot be removed.
   - You can add or remove other events.
   - You can add up to three manual custom metrics.
   - The same event cannot appear as both positive and negative.
3. Click **Next**.

## Controls

Perform the following steps to configure Controls.

1. Set eligibility and exclusion:
   - Select **All users** or **Filter users by segment criteria**.
   - Optional: Exclude users.
   - Click **Show count** to view the eligible audience size.
   - Click **Reset filters** to clear the criteria.
2. Set daily send limits:
   - Define the minimum and maximum number of communications that an end user can receive per day.
   - If this range exceeds your workspace global frequency cap, MoEngage displays a warning with a link to the frequency capping settings.
3. Optional: Add time slots.
   - Turn on **Add time slots**.
   - For each slot, enter the **Name**, **From**, and **To** values.
   - Optional: Click **Set send limits** to add a per-slot minimum and maximum.
   - Overlapping slots are not allowed.
   - A slot minimum cannot exceed the policy maximum.
   - The **Slots preview** shows your slots on a 24-hour timeline.
4. Set the **Policy control group** percentage. The default value is 10%.
5. Click **Save policy**.

# Manage Policies

The **Campaign decisioning policy** page lists all the policies that you create, along with the following details:

- Status
- Last updated date
- Active campaigns
- Decisions made
- Policy performance

You can perform the following actions:

- Search by policy name.
- Filter by status.
- Use the ellipsis icon on a policy row for the available actions.
- Open a policy to edit it.
