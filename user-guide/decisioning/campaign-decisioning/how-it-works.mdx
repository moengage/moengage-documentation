AI Campaign Decisioning determines the best message copy for each end user in your Push campaigns. A Campaign Decisioning Policy contains the goal and guardrails. The AI learns across campaigns which content works for which end users and then delivers the variation most likely to convert for each end user.

# Policy Components

A Campaign Decisioning Policy includes the following:

- **Reward event:** Each policy has one reward event that defines success, such as Product purchased.
- **Performance metrics:** Additional performance metrics are tracked as positive or negative signals so that you can measure impact beyond the reward event.
- **Guardrails:** You define the eligible audience, daily send limits, optional time slots, and policy control group. The AI operates only within these boundaries. Your workspace global frequency cap also applies.

# Content Selection

MoEngage selects content in the following way:

1. You create several complete message variations for a campaign.
2. Content Intelligence auto-labels each variation by using your Content Labels taxonomy.
3. The policy learns which labels each end user responds to and delivers the variation most likely to convert for that end user.

# Sending Logic

Even after the AI selects the best variation for an end user, policy guardrails and the global frequency cap determine whether the message is sent:

1. **Policy limits** apply first. These include the policy maximum sends per end user and any time-slot limits.
2. **Global frequency cap** applies next. This is your workspace-level limit on messages per end user.

Some AI-selected messages are not sent because the global frequency cap takes precedence. This behavior is expected.

# Your Role

Your role includes the following:

- **Strategic intent:** Define the reward event and performance metrics that represent your business goals.
- **Governance:** Set the audience, send limits, time slots, and control group that keep sending within your rules.
- **Creative input:** Provide a diverse set of complete message variations so that the AI has strong copy to choose from for each end user.
