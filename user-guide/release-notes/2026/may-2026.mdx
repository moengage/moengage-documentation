## Decisioning Agent Analytics (Early Access)

MoEngage has introduced the Decisioning Agent Analytics dashboard for Campaign Decisioning. This view helps you measure the incremental value generated by your Decisioning Agents by comparing an AI-optimized Agent Treatment Group against a baseline Agent Control Group.

**Key Highlights:**

- **Engagement Uplift**: Track the net percentage increase in engagement achieved by the AI engine compared to a non-optimized baseline.
- **Operational Summary**: Review quick cards for Decisions Made, Campaigns Sent, Active Channels, and overall Engagement Uplift.
- **Treatment vs. Control Comparisons**: Use performance summary tables that update to show granular event metrics, including positive signals such as clicks and purchases and negative signals such as unsubscribes.
- **Channel and Campaign Breakdowns**: Identify top-performing assets using donut and bar charts for channels, and filter or sort the campaign performance table by Sent, Delivered, or CTR.

<Note>
  This feature is in Early Access. Phase 1 focuses on Engagement Uplift. Conversion metrics and CSV exports are planned for later phases.
</Note>

For more information, refer to [Decisioning Agent Analytics](/user-guide/decisioning/campaign-decisioning/decisioning-agent-analytics).

## Custom Formula Ranking Strategy for Offer Decisioning

MoEngage has introduced the Custom Formula ranking strategy for Offer Decisioning. This strategy lets you define exactly which signals matter and how much weight each one carries when ranking offers for a customer, with scores recalculated in real time.

**Key Highlights:**

- **Fixed Value Attributes**: Apply organization-level goals stamped on each offer at creation, such as Boost AOV, Improve Retention, or Acquire New Users. The formula weight reflects how much each goal should drive ranking.
- **Dynamic Value Attributes**: Apply user-level signals, such as Category Affinity, Churn Propensity, or Spend Tier, that adjust the rank based on who receives the offer.
- **Real-Time Scoring**: Combine fixed and dynamic attributes into a single score that is both commercially intentional and relevant to each user.

For more information, refer to [Offering Attributes](/user-guide/decisioning/offer-decisioning/create-offering-attribute), [Custom Formula Ranking Strategy](/user-guide/decisioning/offer-decisioning/custom-formula-ranking-strategy), and the [FAQs on Decision Policy](/user-guide/decisioning/offer-decisioning/faqs-on-decision-policy).

## Native SDK Support for MoEngage Personalize

MoEngage Personalize now supports fetching personalized content directly through the MoEngage SDK on Android, iOS, React Native, and Flutter. Previously, the only way to fetch this content was by calling the Personalize Fetch API directly, which required managing authentication, API secrets, custom network logic, and error handling.

**Key Highlights:**

- **No Auth Token Management**: The SDK handles user identity and authentication internally, so you call the method without passing credentials with every request.
- **Session and Lifecycle Alignment**: Because the fetch happens through the SDK already initialized in the app, it aligns with the user's session state without syncing user context separately.
- **Built-in Error Handling**: The SDK returns structured failure callbacks with standardized reason codes, such as `NETWORK_ERROR` and `INVALID_KEY`.

For more information, refer to the Personalize SDK guides for [Android](/developer-guide/android-sdk/personalize/personalize-sdk), [iOS](/developer-guide/ios-sdk/personalize/personalize-sdk), [React Native](/developer-guide/react-native-sdk/personalize/personalize-sdk), and [Flutter](/developer-guide/flutter-sdk/personalize/personalize-sdk). For web, refer to [Self-Handled Personalize API Experiences](/developer-guide/personalize-sdk/sdk-integration/self-handled-personalize-api-experiences).

## In-App Merlin AI: Image as Reference

The In-App Merlin AI template generator now accepts an image alongside your text prompt. You can upload a PNG of a design, such as a screenshot or a Figma export, and Merlin AI generates an HTML template based on the reference.

**Key Highlights:**

- **Image Reference**: Attach a PNG with your prompt, then refine the result with follow-up prompts in the same way as text-only generation.
- **Design Tool Workflow**: Export a frame from Figma, Photoshop, or Sketch as a PNG and upload it to convert the design into an In-App template.
- **Standard Output**: Every generated template includes MoEngage tracking, SDK-optimized rendering, and responsiveness.

This feature is available wherever the Merlin AI template generator is enabled.

For more information, refer to [Use a Reference Image](/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-in-app-template-generator/merlin-ai-in-app-template-generator#use-a-reference-image).

## MoEngage Assist Chrome Extension for Web SDK

MoEngage Assist is a Chrome extension that helps internal teams and customers validate and debug Web SDK integrations directly in the browser, without screen shares or support tickets for routine checks.

**Key Highlights:**

- **Automatic Validation**: Flags common misconfigurations, such as an incorrect Service Worker path, initialization errors, and data center validations.
- **Campaign Inspection**: Inspect Cards, Personalize, and On-site Messaging campaigns to see what is configured, what qualifies, and why a campaign is not firing.
- **Render All for Web Personalization**: Preview campaigns on any page without affecting live impressions or analytics.
- **Real-Time Events and Issues View**: See events firing as you navigate, and review everything tied to a Web SDK integration in one place for triage.

For more information, refer to [MoEngage Assist Chrome Extension](/developer-guide/web-sdk/integration-validation/moengage-assist-chrome-extension).

## Web SDK Support for MCP UI Apps

The MoEngage Web SDK now supports MCP UI Apps. MCP UI Apps are interactive mini-apps that run inside AI chat interfaces such as ChatGPT and Claude, letting users take actions without leaving the conversation.

**Key Highlights:**

- **Track User Behavior**: Capture user behavior in real time from within MCP UI Apps.
- **Trigger On-site Messages**: Deliver On-site Messaging (OSM) campaigns inside the app.
- **Serve Cards**: Show Cards to users within the AI chat interface.

For more information, refer to [Integrate MoEngage with MCP UI Apps](/developer-guide/web-sdk/other-supported-web-sdk-integration/integrate-moengage-with-mcp-ui-apps).

## Portfolio Support in Partner Integrations

MoEngage now supports routing partner integration events to specific projects within multi-app workspaces. This keeps localized analytics and segments accurate and enables cross-brand campaigns based on behavior across your portfolio.

**Key Highlights:**

- **Supported Sources**: Available for CDP partners (Segment, mParticle, and Adobe), file imports (CSV, S3, and SFTP), data warehouse imports (BigQuery, Snowflake, and Databricks), and all connected sources.
- **Configuration**: For Segment, set the target project in the new Project name field in the Track Call action mapping. For mParticle and other partners, pass the project name as the event attribute `moe_project_name` in the event payload.
- **Availability**: Live across all data centers and backward compatible. Workspaces that are not multi-app see no change in behavior.

<Note>
  This release supports event routing only. User profile imports and cohort syncs from these partners continue to be ingested at the portfolio root level. Partners using the Data API do not support Portfolio routing yet.
</Note>

## Enhanced User Profile

MoEngage has revamped the user profile, starting with DC3. The update adds profile management actions and improves the overall interface.

**Key Highlights:**

- **Delete a User**: Delete a user directly from the interface based on roles and permissions. The action generates an audit log entry.
- **Email Subscription Status**: Change a user's email subscription status. The change generates an event, triggers the corresponding SendGrid subscription update, and is recorded in the audit log.
- **SMS Unsubscribe**: Unsubscribe a user from the SMS channel.
- **Identifier Visibility**: View any user attribute marked as an identifier in a Multi-ID workspace in the basic details section.
- **Interface Improvements**: Use more discoverable tabs, improved event filtering, consistent terminology, and faster test email performance.

<Note>
  The interface improvements roll out across data centers independently and are currently live in DC3. Delete and subscription-change actions are enabled in phases.
</Note>

For more information, refer to [User Profile](/user-guide/data/user-data/user-profile).

## Campaign Management Improvements

MoEngage has shipped a set of usability improvements to campaign management.

**Key Highlights:**

- **Copy Link**: Copy a campaign link directly from the All Campaigns page to share with your team.
- **Search Retention on Drafts**: A search term entered on the All Campaigns page now carries over to the Drafts tab, so you do not need to search again when switching tabs.
- **Alert Name Wrapping**: Alert names now wrap up to a limit on the All Alerts page instead of being truncated.
- **Action Icons**: Added icons to actions to improve visual clarity and accessibility.
